# 0.1.3 多页面、事件与显式重连

日期：2026-11-04。版本：0.1.3-poc，VS2019/v142、C++14、x64。0.1.2已验收包继续保留。本轮在该基础上新增6个共享工具，UI/CLI/MCP/HTTP调用同一Service，工具总数27。

## 1 实际功能与操作

| 工具 | 参数（均另需profileId/lease） | 行为 |
| --- | --- | --- |
| page_list | 无额外必需参数 | 返回pages/activePageId/maximumPages；只登记本实例页面及允许来源的子弹窗 |
| page_open | url（允许HTTP(S)来源或about:blank） | 新建页面、独立CDP session、应用区域设置、导航并选择；返回pageId |
| page_switch | pageId | 校验归属和当前来源，切换活动页面；旧元素ref全部失效 |
| page_close | pageId | 只关闭本实例该页面；活动页关闭后选剩余已连接页，最后一页关闭后可重新page_open |
| browser_events | 可选after、eventEpoch、limit(1–100，默认50) | 有界元数据事件轮询和游标分页；不提供实时推送 |
| browser_reconnect | 无额外必需参数 | 显式重连相同自有进程，重建仍存活的授权页面会话，绝不重放网页动作 |

桌面新增“页面列表、新页面、切换、关闭选中页、页面事件、显式重连”。先启动环境，再用地址框新建页面；页面下拉框显示本地ID前缀与当前页标记。选中一项后点切换才改变动作目标；点击/填写/快照仍作用于当前活动页。“关闭选中页”可关闭未活动的指定页面；外部弹窗出现后手动刷新页面列表。

控制租约仍以Profile为范围，不因新建标签页另计环境或席位。单个浏览器最多32个**受管页面**；这是本机防无界创建预算，不代表中央免费额度、后台并发槽或所有弹窗数量。关闭受管页释放此预算。普通系统浏览器及同实例未登记的启动空白页不会自动接管。

每页使用独立session；新页面和显式收纳的弹窗应用UA/语言/时区。page_open先在空白页应用配置再导航；弹窗收纳发生于创建后，首请求/首段脚本可能已运行，不能据此声称完整弹窗预注册或Worker一致性。未知about:blank弹窗暂不自动收纳，待其进入明确授权来源再刷新。

## 2 元数据事件

缓存Page.frameNavigated/frameDetached/loadEventFired、Runtime.executionContextsCleared、Target.targetDestroyed/detachedFromTarget及workbench.connectionReplaced。事件只含序号、页面ID、类型及有限frame/loader标识，不保存URL查询、网页正文、输入值或Console/Network正文。最多256条内存事件；旧事件淘汰后返回gap=true及oldestAvailable，不静默伪装为连续记录。

初次调用browser_events可不传游标；结果含cursor:{eventEpoch,after}、more、currentSequence。后续把cursor字段展开传回，按limit翻页。after>0必须提供当前eventEpoch；未来序号、旧实例epoch均拒绝。浏览器重新启动会更换epoch，旧游标不能复用。事件在CDP请求读取及轮询屏障中收取，尚非后台订阅/持久事件日志。

连接重建生成workbench.connectionReplaced事件，gap=true，重连响应eventContinuity明确断连期间可能漏事件。事件marker不等于补齐断连期间历史；事件本身不用于自动补做网站动作。

## 3 超时和显式恢复

CDP每条请求仍有8秒总截止。连接超时后browser_status区分running与cdpConnected；进程仍在而连接已断时，新页面动作返回CDP_DISCONNECTED。先只读或人工核对原业务，再点击“显式重连”或调用browser_reconnect；停止仍无需租约。

重连只读取本受管目录的发现文件，连接127.0.0.1；调用者不能指定任意CDP端点。仅重绑已登记的存活页面，保留本地pageId、进程PID和会话数据，清空旧元素引用。被关/未授权页面不自动重建或导航。失败保留明确断开状态，返回CDP_RECONNECT_FAILED；没有透明写重试、无自动注册/付款重放。

## 4 真实测试与问题修复

tests/integration_pages.py覆盖6组：

1. 独立会话、about:blank新建、区域实际值、来源拒绝、切换后旧ref拒绝。
2. 实际鼠标触发同源弹窗、允许来源收纳、另一来源排除、跨Profile页面ID拒绝。
3. 事件分页无重复、90次实际导航触发缓冲淘汰、gap/预算、事件不含查询canary。
4. 页面提交后阻塞12秒，8秒CDP超时返回unknown；服务器只提交1次，显式重连后仍为1次，页面ID保留、旧ref失效、断连标记可见。
5. 真实创建到32页，第33次拒绝；关闭回收页面预算。
6. 撤销后的新建/关闭/重连拒绝；关闭最后一页、重新打开、旧页面ID/旧实例游标拒绝。

桌面测试新增真实下拉选择及六按钮调用，仍回归注册/登录、隔离、归档/恢复、确认删除。HTTP增加5次实际页面/事件调用，每配置47次请求；官方MCP列出27工具。其他生命周期、存储29组、124条浏览器命令、代理、区域与18项协议检查继续回归。

发现并修复：新建about:blank被旧就绪条件排除，改为允许明确空白导航并匹配本次loader；切换后必须清除旧ref；页面动作结果不再刷新页面下拉框，防止覆盖用户选择。事件测试最初误用填写秘密canary作为已知URL，触发通用测试客户端约束；改用专用查询标记，仅检查事件不含URL，保留初次失败证据。

最终证据位于[本轮证据目录](execution/evidence/2026-11-04-multipage/)，[验收汇总](execution/evidence/2026-11-04-multipage/summary.json)记录实际二进制哈希和测试范围。最终原生构建为native-20261104-114051，CMake全量回归为run-20261104-114400；Debug/Release均通过，桌面两套也通过。每套通过CTest 3项、存储29组、浏览器124条命令、HTTP 47次请求及5类原始协议拒绝、27个官方MCP工具、6组多页面/事件/故障恢复及18项协议检查；HTTP/SOCKS5、生命周期、进程恢复和区域配置继续通过。原生解决方案零警告、零错误。最终制品验证在打包后补录。旧失败及先前0.1.2证据不覆盖。
