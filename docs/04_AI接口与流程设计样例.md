## 1 通用约定

- API 前缀为 `/api/v1`，监听回环；认证令牌通过受保护配置获得，不放在 URL。
- 示例时间使用带时区的 ISO 8601；机器日志可存 UTC，用户显示使用任务时区。
- ID 为不透明字符串，不能使用名称、标签索引或默认当前页面代替。
- 写入需作用域授权和有效租约；所有入口共享同一 PolicyService。
- `requestId` 用于请求去重和追踪，不保证目标站点业务幂等。
- 长任务返回 operation/run ID；客户端断开不自动取消，取消有独立接口。
- `SecretRef`、`ArtifactRef` 和元素引用均须再次校验所属用户、任务和范围。

## 2 资源接口草案

| 方法与资源 | 用途 | 关键限制 |
| --- | --- | --- |
| GET `/capabilities` | 驱动和协议能力 | 按驱动/版本返回，不能总报支持 |
| GET/POST `/profiles` | 列出或创建环境 | 目录限受管根；免费主体全局容量10，创建/导入/克隆原子预留 |
| GET/PATCH `/profiles/{id}` | 查询或修改配置 | running 时只改允许热更新项 |
| POST `/profiles/{id}/start` | 启动环境 | 同Profile不多进程并开；免费容量10/默认10槽、配置/代理能力校验，拒绝不扣费 |
| POST `/profiles/{id}/stop` | 停止受管浏览器 | 不误停用户其他浏览器 |
| POST `/profiles/{id}/archive` | 归档环境 | 有活动任务时先处理引用 |
| POST `/spaces` | 创建任务空间 | 必须指定 profileId 和 scope |
| GET `/spaces/{id}` | 查询空间 | 身份边界与控制权分开返回 |
| POST `/spaces/{id}/tabs` | 创建标签 | URL 与后续重定向检查域范围 |
| POST `/spaces/{id}/leases` | 获取控制权 | Profile 默认单写入租约 |
| POST `/leases/{id}/release` | 主动释放租约 | generation 失效，等待请求不得写入 |
| POST `/spaces/{id}/handoff` | 进入人工接管 | 返回排空与未知结果信息 |
| POST `/tabs/{id}/snapshot` | 页面语义快照 | 带 frame 和文档版本信息 |
| POST `/actions` | 单个或有界批次动作 | 单次动作和后置断言逐项记录 |
| GET `/operations/{id}` | 查询长操作 | outcome 不明不能报成功 |
| POST `/operations/{id}/cancel` | 请求取消 | 区分已取消和太晚无法撤销 |
| GET `/tabs/{id}/console` | Console/异常 | 范围、游标、脱敏 |
| GET `/tabs/{id}/network` | Network 摘要 | 正文读取需要额外能力 |
| GET/POST `/workflows` | 管理流程 | 草稿/发布版本分离 |
| POST `/workflows/{id}/validate` | 校验流程 | 图、类型、能力、循环和预算 |
| POST `/workflows/{id}/publish` | 固定发布版本 | 不可变 hash |
| POST `/runs` | 执行固定版本流程 | 引用 profile、scope、输入和预算 |
| GET `/runs/{id}` | 状态、步骤和结果 | 返回实际已完成步骤 |
| POST `/runs/{id}/pause` | 暂停后续派发 | 不承诺撤销已发动作 |
| POST `/runs/{id}/resume` | 校验后继续 | 重获租约，重新观察页面 |
| POST `/runs/{id}/stop` | 终止运行 | 记录未决业务动作 |
| GET `/artifacts/{id}` | 获取证据或下载 | 不能直接暴露任意文件路径 |
| GET `/events` | REST 事件流 | 此 SSE 不等同于 MCP 传输实现 |
| GET/POST `/web-test-projects` | 查询或创建 Web 测试项目 | 环境地址、角色与凭据引用分离 |
| POST `/tabs/{id}/inspect` | 开启元素选取或检查指定候选 | 选取不触发业务点击，不自动取得控制权 |
| POST `/assertions/evaluate` | 立即检查页面或业务断言 | 返回期望/实际与证据，不伪装成动作成功 |
| GET/POST `/test-cases` | 管理功能用例草稿 | 引用已有 workflow 动作版本和测试数据 |
| POST `/test-cases/{id}/validate` | 校验用例与前后置条件 | 角色、域名、秘密引用、断言和清理能力 |
| POST `/test-cases/{id}/publish` | 固定可回归用例版本 | 运行不读取可变草稿 |
| GET/POST `/test-suites` | 管理测试集和数据驱动组合 | 用例版本与执行策略固定 |
| POST `/test-runs` | 运行单用例或测试集 | 按环境/角色准备基线，复用原执行引擎 |
| GET `/test-runs/{id}` | 查询功能测试结果 | 区分通过、失败、阻断、跳过、不稳定、未决 |
| POST `/test-runs/{id}/cancel` | 取消并执行允许的清理 | 不承诺取消已发生的业务提交 |
| GET `/test-runs/{id}/report` | HTML/JSON/JUnit 测试报告 | 脱敏、版本化，原始结果状态可追踪 |

正式接口的查询、分页、幂等和版本兼容策略在 T021 冻结。导出秘密、清理 Cookie、请求重放和原始 CDP 不属于默认工具集。

## 3 创建身份环境

请求示例：

```json
{
  "name": "测试后台环境",
  "driver": "managed-chromium",
  "templateId": "windows-test-default",
  "proxyRef": "proxy_test_01",
  "environment": {
    "language": "zh-CN",
    "timezone": "Asia/Shanghai",
    "viewport": { "width": 1440, "height": 900 }
  },
  "tags": ["测试", "报表"]
}
```

响应示例：

```json
{
  "profileId": "prf_demo_01",
  "state": "stopped",
  "configVersion": 1,
  "capabilities": {
    "persistentLogin": true,
    "semanticSnapshot": true,
    "engineFingerprint": false,
    "embeddedBrowser": false
  },
  "environmentVerification": "pending"
}
```

`persistentLogin` 表示支持持久环境，不保证能迁移其他软件的加密 Cookie。环境参数在实际启动并检测后才有 `effective` 状态。

## 4 创建任务空间与租约

```json
{
  "profileId": "prf_demo_01",
  "name": "报表导出演练",
  "scope": {
    "allowedOrigins": ["http://127.0.0.1:18765"],
    "capabilities": [
      "page.observe",
      "page.navigate",
      "page.form",
      "page.click",
      "file.download"
    ]
  },
  "budget": {
    "maxActions": 40,
    "maxDurationMs": 180000,
    "maxSnapshotChars": 16000
  },
  "controlPolicy": "profile-single-writer"
}
```

返回 `spaceId`、`controlState`、`sharedIdentity: true` 和 `leaseRequired: true`。同 Profile 中 Space 分离不会复制独立账号身份；该事实应在 UI 及接口中同时表达。

租约响应草案：

```json
{
  "leaseId": "lease_demo_01",
  "profileId": "prf_demo_01",
  "spaceId": "spc_demo_01",
  "generation": 7,
  "expiresAt": "2026-11-03T18:30:00+08:00",
  "scope": { "tabIds": ["tab_demo_01"] }
}
```

请求 token 的主体必须与租约主体匹配。客户端不能通过填入更大的 generation 取得控制权；generation 由服务端分配并在每次派发前核验。

```json
{
  "snapshotId": "snap_demo_42",
  "tabId": "tab_demo_01",
  "documentEpoch": 12,
  "url": "http://127.0.0.1:18765/report",
  "title": "测试报表",
  "truncated": false,
  "content": "报表筛选\n开始日期 [ref=r1]\n结束日期 [ref=r2]\n查询 [ref=r3]\n导出 CSV [ref=r4]",
  "refs": [
    {
      "ref": "r3",
      "role": "button",
      "name": "查询",
      "frameRef": "frm_main",
      "locator": { "role": "button", "name": "查询", "exact": true },
      "unique": true,
      "visible": true,
      "enabled": true
    }
  ]

```

示例 refs 仅展示一个元素；正式结果应保证所有输出 ref 可解析。内部保存 frame/session/backendNodeId；它们不作为可以由外部 AI 任意拼接的全局定位符。

可访问名称相同的两个按钮必须返回多个匹配或要求限定区域，不能自动点第一个。导航后 `snap_demo_42` 失效；对旧 ref 的动作返回 `STALE_ELEMENT_REF`。

## 6 单动作与业务断言

```json
{
  "requestId": "req_demo_query_01",
  "spaceId": "spc_demo_01",
  "tabId": "tab_demo_01",
  "lease": { "id": "lease_demo_01", "generation": 7 },
  "expectedDocumentEpoch": 12,
  "action": {
    "type": "click",
    "target": { "snapshotId": "snap_demo_42", "ref": "r3" }
  },
  "postcondition": {
    "type": "textVisible",
    "locator": { "testId": "report-status" },
    "expectedText": "查询完成"
  },
  "timeoutMs": 10000
}
```

返回必须区分：动作未发出、动作已发出且后置条件通过、动作已发出但未验证、结果未知。只有后置条件通过才能称本例业务步骤成功。

有界批次动作依次执行，每个动作都有 stepId 和结果。出现文档变化、权限失效或后置条件失败，停止后续动作并返回 `completedSteps`、`failedStep` 和 `unexecutedSteps`。

| 工具 | 输入重点 | 输出重点 | 读写 |
| --- | --- | --- | --- |
| `browser_capabilities` | driver/profileId | 支持功能、限制与协议版本 | 读 |
| `browser_list_profiles` | 过滤条件 | 获授权环境摘要，不含秘密 | 读 |
| `browser_create_space` | profileId/scope/budget | spaceId、身份共享说明 | 资源写 |
| `browser_acquire_control` | spaceId | 租约或占用信息 | 控制写 |
| `browser_list_tabs` | spaceId | 当前范围标签 | 读 |
| `browser_open_tab` | spaceId/url | tabId、最终 URL | 页面写 |
| `browser_snapshot` | tabId/范围/预算 | 文档版本、语义和 refs | 读 |
| `browser_action` | tab/lease/action/assertion | 动作结果、证据与文档版本 | 页面写 |
| `browser_extract` | snapshot/Schema | 校验通过的数据或缺失字段 | 读 |
| `browser_read_console` | tab/cursor/filter | 脱敏日志和游标 | 读 |
| `browser_read_network` | tab/cursor/filter | 脱敏请求摘要 | 读 |
| `workflow_validate` | 流程草稿 | 校验错误、缺失能力 | 读 |
| `workflow_run` | 版本/input/profile | runId、运行状态 | 流程写 |
| `workflow_status` | runId | 已完成步骤、结果、证据 | 读 |
| `workflow_control` | runId/操作 | 暂停、停止或恢复结果 | 控制写 |
| `browser_handoff` | spaceId/原因 | 接管状态、未决动作 | 控制写 |
| `web_test_projects` | 项目过滤条件 | 环境与授权角色摘要 | 读 |
| `browser_inspect_element` | tabId/选取模式/候选 | 元素信息、唯一定位与支持动作 | 控制界面；选取不执行业务 |

| `web_test_validate` | 用例或测试集草稿 | 前置、动作、断言和清理校验 | 读 |
| `web_test_run` | 固定用例/集版本/环境/数据 | testRunId、数据参数与状态 | 测试写 |

工具描述和 annotations 不承担安全边界；服务端独立判定真实权限。外部 AI 仍须经过授权范围，不能把工具参数中传来的 `safe: true` 当作可信依据。

MCP 最小验收：initialize 版本协商、initialized、tools/list、tools/call、错误、超时、取消、断线、未知工具和大结果分页。stdio 每行一条 UTF-8 JSON-RPC 消息，stdout 不混入启动横幅。

## 8 流程 JSON 示例

示例任务：打开本地报表页，填写日期，查询，验证结果，再下载 CSV 并校验。它是目标 DSL 的设计样例，当前没有解释器；`${input.xxx}` 为受限表达式语法示意。

```json
{
  "schemaVersion": "0.1",
  "workflowId": "wf_report_demo",
  "version": 1,
  "name": "测试报表导出",
  "inputSchema": {
    "type": "object",
    "required": ["startDate", "endDate"],
    "properties": {
      "startDate": { "type": "string", "format": "date" },
      "endDate": { "type": "string", "format": "date" }
    },
    "additionalProperties": false
  },
  "policy": {
    "allowedOrigins": ["http://127.0.0.1:18765"],
    "maxDurationMs": 180000,
    "maxLoopIterations": 20,
    "control": "profile-single-writer"
  },
  "entry": "open_report",
  "steps": [
    {
      "id": "open_report",
      "type": "navigate",
      "url": "http://127.0.0.1:18765/report",
      "timeoutMs": 10000,
      "next": "fill_start"
    },
    {
      "id": "fill_start",
      "type": "fill",
      "locator": { "testId": "start-date" },
      "value": "${input.startDate}",
      "next": "fill_end"
    },
    {
      "id": "fill_end",
      "type": "fill",
      "locator": { "testId": "end-date" },
      "value": "${input.endDate}",
      "next": "query"
    },
    {
      "id": "query",
      "type": "click",
      "locator": { "role": "button", "name": "查询", "exact": true },
      "postcondition": {
        "type": "textVisible",
        "locator": { "testId": "report-status" },
        "expectedText": "查询完成"
      },
      "timeoutMs": 10000,
      "retry": { "maxAttempts": 1 },
      "next": "check_rows"
    },
    {
      "id": "check_rows",
      "type": "assert",
      "condition": {
        "type": "attributeNumberGreaterThan",
        "locator": { "testId": "report-table" },
        "attribute": "data-row-count",
        "value": 0
      },
      "next": "export_csv"
    },
    {
      "id": "export_csv",
      "type": "clickAndWaitDownload",
      "locator": { "role": "button", "name": "导出 CSV", "exact": true },
      "downloadPolicy": {
        "directoryRef": "run-downloads",
        "maxBytes": 10485760,
        "extension": ".csv"
      },
      "saveAs": "reportFile",
      "retry": { "maxAttempts": 1 },
      "next": "verify_file"
    },
    {
      "id": "verify_file",
      "type": "verifyArtifact",
      "artifact": "${steps.export_csv.reportFile}",
      "checks": {
        "minBytes": 1,
        "csvRequiredColumns": ["date", "amount"]
      },
      "next": "done"
    },
    { "id": "done", "type": "end", "result": "success" }
  ],
  "onFailure": {
    "capture": ["snapshot", "screenshot", "console", "network-summary"],
    "transition": "failed"
  },
  "onUnknownOutcome": {
    "capture": ["snapshot", "screenshot", "network-summary"],
    "transition": "waiting-user-review"
  }
}
```

`clickAndWaitDownload` 先注册下载观察再派发点击，避免漏掉快速下载。下载校验失败不自动重复点击；由执行器判断是否已有完成文件并保留证据。

UI 应将该 JSON 显示为可编辑步骤，版本发布后固定 hash。录制器、AI 生成器和画布使用同一 Schema，不能维护互不兼容的三套流程格式。

## 9 运行状态与错误语义

| 状态 | 含义 | 允许的后续处理 |
| --- | --- | --- |
| queued | 等待资源与租约 | 取消或开始 |
| running | 正在执行动作或断言 | 暂停、接管、停止 |
| pausing | 停止派发并排空已发操作 | 转暂停、人工或结果未知 |
| paused | 已停止派发且无未知写结果 | 校验后恢复或停止 |
| waiting-user | 需要登录、权限或业务核对 | 人工处理并明确交回 |
| succeeded | 所有要求的后置条件通过 | 查看/导出结果 |
| failed | 已知失败，可解释原因 | 修复草稿或新建 attempt |
| outcome-unknown | 写入可能已经发生，结果未确认 | 先核对业务状态，不盲目重试 |
| cancelled | 已在安全边界停止 | 查看已完成动作，不承诺回滚 |

统一错误示例：

```json
{
  "requestId": "req_demo_query_01",
  "error": {
    "code": "STALE_ELEMENT_REF",
    "message": "页面文档已更新，请重新获取快照",
    "retryable": true,
    "outcome": "not-dispatched",
    "context": {
      "spaceId": "spc_demo_01",
      "tabId": "tab_demo_01",
      "expectedEpoch": 12,
      "actualEpoch": 13
    },
    "evidenceRefs": ["art_snapshot_after_nav"]
  }
}
```

`retryable: true` 表示可在修复前提后重新请求，不表示客户端可复用旧参数自动重发。本例应重新观察并定位。

| 错误码 | 典型触发 | 自动重试 |
| --- | --- | --- |
| `UNSUPPORTED_CAPABILITY` | 驱动不支持高级指纹/嵌入/特定控件 | 否，变更驱动或流程 |
| `PERMISSION_DENIED` | 域名或操作不在授权范围 | 否 |
| `CONTROL_NOT_OWNED` | 无有效租约或正在人工接管 | 否，重新获取控制权 |
| `LEASE_EXPIRED` | 等待期间租约失效 | 否，核验后获取新租约 |
| `AMBIGUOUS_TARGET` | 定位命中多个节点 | 否，缩小范围 |
| `STALE_ELEMENT_REF` | 导航/重绘后旧引用失效 | 只在未派发时允许重新观察 |
| `FRAME_UNAVAILABLE` | OOPIF session 断开 | 只读可重建上下文；写入先核对 |
| `POSTCONDITION_TIMEOUT` | 点击已发出但业务断言未通过 | 不自动重放写动作 |
| `BUSINESS_OUTCOME_UNKNOWN` | 提交后连接中断 | 否，核对业务结果 |
| `PROXY_UNAVAILABLE` | 代理失败 | 不切换直连 |
| `DOWNLOAD_INCOMPLETE` | 下载取消或文件缺失 | 先检查已有下载和站点状态 |
| `BUDGET_EXCEEDED` | 时间、动作或模型预算耗尽 | 暂停等待策略处理 |
| `CANCEL_TOO_LATE` | 操作已发送或已完成 | 记录结果，不声称已撤销 |

### 13.2 用例与断言

下例假设已经发布 `wf_submit_login_form` 版本 1：导航登录页、填写账号/密码并提交。它不预设一定登录成功，由测试用例的断言判断正负向业务结果；此模板仍使用既有 workflow Schema。

```json
{
  "caseId": "tc_login_ok",
  "caseVersion": 1,
  "projectId": "web_demo",
  "name": "正确账号密码登录",
  "tags": ["smoke", "login"],
  "workflowVersionRef": { "id": "wf_submit_login_form", "version": 1 },
  "baseline": { "mode": "fresh-unauthenticated" },
  "dataRef": "dataset_login_valid",
  "bindings": {
    "loginPath": "${project.routes.login}",
    "username": "${data.username}",
    "passwordRef": "${data.passwordRef}"
  },
  "elementMap": {
    "username": { "testId": "login-username" },
    "password": { "testId": "login-password" },
    "submit": { "role": "button", "name": "登录", "exact": true }
  },
  "assertions": [
    { "type": "urlPath", "expected": "/dashboard", "timeoutMs": 10000 },
    {
      "type": "textEquals",
      "locator": { "testId": "current-user" },
      "expected": "${data.displayName}",
      "timeoutMs": 5000
    }
  ],
  "cleanup": {
    "workflowVersionRef": { "id": "wf_logout_demo", "version": 1 },
    "on": ["passed", "failed", "cancelled"],
    "failurePolicy": "block-dependent-cases"
  },
  "retry": { "maxAttempts": 1 }
}
```

`${project.xxx}`、`${data.xxx}` 和 SecretRef 由测试层解析为经过类型检查的 workflow 输入，不支持任意宿主表达式。密码只在动作派发时解析，报告不回显实际密码。

错误密码用例从未登录基线开始，使用固定无效密码数据，断言失败提示且当前用户不存在；不能把工作流没有抛错当作负向测试通过。注册模板同样绑定页面实际元素，使用唯一账号和受控清理步骤；表单报错、重复账号和未创建状态是不同断言。

在 `outcome-unknown` 时，先执行只读核对或进入人工处理，暂停原用例的变更型 cleanup。只有明确确认已创建资源或业务状态后才进行定向清理，避免继续写入使结果更难判断。

### 13.3 测试集与命令行

```json
{
  "projectId": "web_demo",
  "suiteVersionRef": { "id": "suite_auth_smoke", "version": 1 },
  "environment": "dev",
  "filter": { "tagsAny": ["smoke", "login", "register"] },
  "execution": {
    "maxParallelProfiles": 2,
    "caseIsolation": "fresh-profile",
    "stopOnContamination": true,
    "allowFlakyPass": false,
    "timeoutMs": 300000
  },
  "reports": ["html", "json", "junit"]
}
```

命令形式草案：

```text
workbench test run --project web_demo --suite suite_auth_smoke --version 1 --env dev --tag smoke --report-dir .\test-results
```

`--report-dir` 为 CLI 用户选择的受控导出目录；MCP/REST 使用 artifact 引用，不能由网页任意指定宿主路径。无 UI 命令仍遵守浏览器运行条件，人工验证用例在无人值守模式中应返回 blocked。

退出码草案：0 表示选中且应执行的用例全部稳定通过，且没有未说明的跳过或空选择；1 表示功能/断言失败、不允许的 flaky、未允许的跳过或未显式允许的空选择；2 表示配置、服务、凭据、整体超时、污染环境或未决业务状态造成阻断；3 表示用户取消。混合结果按 2（阻断/unknown）→3（取消）→1（失败）→0 的优先级返回，报告保存所有计数。普通步骤断言超时属于用例失败，整体执行超时属于阻断。显式允许跳过时仍记录其原因和数量，不将其计入通过数。

重跑使用新 attempt，保留原始失败，不通过覆盖历史生成“全绿”。JUnit 对 blocked 等状态采用明确映射并附原始状态字段，退出码不能因为 JUnit 映射成 skipped 而变为成功。

## 17 分页、并发更新、事件重连和错误映射

| 契约 | 规定 | 反例验收 |
| --- | --- | --- |
| 列表分页 | limit 默认 50、最大 200，opaque cursor 绑定主体/过滤/排序与快照版本 | 用其他主体 cursor、变更过滤或过期返回错误，不漏项伪装完整 |
| 配置并发更新 | 返回 ETag/revision，PATCH 必须 If-Match | revision 不匹配返回 412 CONFIG_REVISION_CONFLICT |
| 请求去重 | 主体+资源+requestId 绑定正文哈希，保留期初定 24h | 同 ID 同正文返回原操作；不同正文返回 409 REQUEST_ID_CONFLICT |
| 长任务接收 | 202 仅表示已受理，结果通过 operation 查询 | 不把接收写成业务成功 |
| 事件重连 | cursor/eventId 去重；REST SSE 支持 Last-Event-ID | 保留窗口外返回 410 EVENT_CURSOR_EXPIRED，重新查询结果 |
| 排队与流控 | 有界队列，超限 429 + Retry-After；已派发不透明重发 | 超大输入 413、取消竞态与背压有测试 |
| 域和资源 | 每次跳转/子请求/文件/adapter 访问都再校验作用域 | 改 ID 或重定向不能借用他人秘密与 Profile |

MCP 通过协议层错误与 tool result isError 映射同一业务 code；HTTP 状态不能代替 outcome。业务失败如注册重复可按用例预期成为断言通过，服务鉴权失败则为工具错误。

| 补充错误码 | 含义与处理 |
| --- | --- |
| FIXTURE_UNAVAILABLE | 组件未配置/版本不符/端口冲突；blocked，不无限重试 |
| MESSAGE_WAIT_TIMEOUT | 未取得符合本用例的消息；不取其他用例的验证码 |
| TEST_ENVIRONMENT_CONTAMINATED | 清理失败或状态不明；阻断依赖并隔离环境 |
| MOCK_SCOPE_MISMATCH | 规则越权或未安装；不发送后续受保护动作 |
| VISUAL_BASELINE_MISSING | 无基线；要求创建并审阅，不能默认相同 |
| VISION_TARGET_AMBIGUOUS | 低置信度/多候选/截图过期；重新观察或人工 |
| RUNTIME_UNVERIFIED | 浏览器/Worker 来源或版本未准入；禁止自动运行 |
| MANUAL_STEP_REQUIRED | 真实验证码/硬件/系统权限需要用户；CI blocked |
| COMPENSATION_FAILED | 测试资源补偿失败；保留原业务结果和污染标记 |

## 18 Worker 最小协议边界

Worker 请求包含 protocolVersion、componentVersion、requestId、runId、deadline、能力 token、输入 ArtifactRef/SecretRef 和预算；结果包含 status、outcome、结构化数据、证据引用、截断信息与清理状态。禁止网页提供执行文件、参数模板、模块路径或任意脚本。服务端验证组件版本和请求范围；进程 stdout 只输出协议，stderr 走脱敏日志。

超时先取消，期限后终止受管进程；不误杀其他程序。Worker 崩溃后纯图像比较可以在输入固定时重跑，浏览器写动作仍按 outcome-unknown 核对。临时文件与秘密按 run 清理；缺少清理证据不能把任务标成完全结束。具体实施和验收见 T079/T082–T100。


## 19 v1.3 单一契约与新增原生资源

契约源拟定为 `contracts/public-api.json` 与其引用的 draft-07 schemas；生成运行时校验注册表、OpenAPI3.0.3、MCP 声明、CLI 帮助、SDK 类型和版本化 Agent 手册。定义源使用中立 JSON，生成器是离线开发工具，不把 TS 运行时引入 C++14 服务。OpenAPI3.0.3 与 draft-07 的 null/引用/组合等差异显式转换；不支持的约束报错，不能静默丢失。策略、租约和业务实现仍由共享服务执行。

以下路径均相对于原生 `/api/v1`，为拟定接口，尚不可调用：

| 方法与路径 | 输入/结果要点 | 能力与失败边界 |
| --- | --- | --- |
| GET `/contract` | apiVersion、contractHash、生成器/协议版本、能力摘要 | 不暴露内部实现路径/密钥；SDK/手册可对齐版本 |
| POST `/profile-matrix/scans` | profileIds、静态/有效检测类型；返回 operationId | profile.read，网络观测另授权；逐项 unknown，不报告账号风险 |
| GET `/profile-matrix/scans/{id}` | requested/effective、规则、证据、时间/版本 | 受主体/Profile 过滤，静态与外网耗时分开 |
| GET `/spaces` | 过滤、分页、owner、lease 状态、活动 run | 共享已有分页契约；不是获取写租约 |
| POST `/spaces/{id}/previews` | tabId、上限帧率/宽度/期限；返回 previewId | screen.read；敏感页可拒绝，受全局配额/背压约束 |
| GET `/previews/{id}` | 最新 ArtifactRef、文档/时间、stale/droppedFrames | 主体/Space 再校验；默认不持久化；过期图不能动作定位 |
| DELETE `/previews/{id}` | 释放采样订阅 | 幂等清理，关闭页面或权限失效也回收 |
| POST `/knowledge-packs/imports` | ArtifactRef、dryRun、冲突策略 | 先验证/差异预览，禁止秘密/代码/路径穿越 |
| GET `/knowledge-packs/imports/{id}` | 校验/冲突与操作结果 | 包适用 origin/版本与能力可见，未知字段拒绝 |
| POST `/knowledge-packs/{id}/exports` | 固定 version；返回脱敏 ArtifactRef | 默认不含运行图像/正文/凭据，本机变量重新绑定 |
| POST `/locator-repairs` | sourceRunId、stepId、snapshotId、预期定位语义 | 只读候选与证据，不自动动作，不自动编辑断言 |
| GET `/locator-repairs/{id}` | 旧/新定位、唯一性、歧义、siteVersion | 生成草稿，历史失败保持原样 |
| POST `/locator-repairs/{id}/drafts` | 选定候选、目标 draft revision | If-Match，显式生成/更新草稿；发布仍走既有 publish |
| GET `/diagnostics` | runtime 或 development 模式 | 默认只读/脱敏；缺开发工具不阻断已安装产品运行 |

导入、扫描和导出采用已有 operation/deadline/cancel/outcome 契约；GET 不能触发业务点击或清理。模型不是生成矩阵/知识包/候选的前提。UI/CLI/MCP/SDK 调同一服务，不能由某个 SDK 专门绕过租约。

### 19.1 契约元信息示例

```json
{
  "apiVersion": "1.0-draft",
  "contractHash": "sha256:example-contract-digest",
  "schemaDialect": "http://json-schema.org/draft-07/schema#",
  "openapiVersion": "3.0.3",
  "toolsets": ["basic", "testing", "debug", "admin"],
  "defaultToolset": "basic",
  "capabilityVersion": "example-capabilities-v1",
  "implementationStatus": "design-only"
}
```

示例 hash 是占位符，不可作为实际兼容凭据。客户端应按兼容范围校验 API/契约，不把 hash 改变一概当业务错误；破坏性变更需迁移/拒绝，新增兼容字段可按版本策略接受。Agent 手册包同样标记 contractHash 与适用协议，不由网页内容修改权限。

## 20 快照预算、delta 与 MCP 工具预设

在现有快照请求上增加 mode、baseSnapshotId、depth/maxNodes/maxBytes 和投影选项；客户端与服务端均有限制，服务端上限优先。默认 interactive 200 可操作节点、64 KiB，硬上限初定 512 KiB。请求 delta 时，缓存基准必须匹配实例、Space、Tab、frame、文档和投影范围。下例为一次有效差分；动作仍使用当前 documentEpoch 校验的 ref。

```json
{
  "request": {
    "tabId": "tab-local-register",
    "mode": "delta",
    "baseSnapshotId": "snap-before-validation",
    "maxNodes": 200,
    "maxBytes": 65536
  },
  "response": {
    "snapshotId": "snap-after-validation",
    "baseSnapshotId": "snap-before-validation",
    "mode": "delta",
    "documentEpoch": 7,
    "projectionHash": "example-interactive-root",
    "changes": [
      {
        "kind": "update",
        "ref": "ref-current-email-error",
        "attributes": {"text": "邮箱格式错误", "visible": true}
      }
    ],
    "truncated": false,
    "omittedNodes": 0,
    "bytes": 620,
    "nodes": 1,
    "tokenEstimate": {"value": 180, "method": "example-estimator-v1"}
  }
}
```

base 失效时返回 mode=full、resetReason（例如 DOCUMENT_CHANGED/BASE_EXPIRED/PROJECTION_CHANGED/DELTA_TOO_LARGE），并返回新的 snapshotId；不能声称空 changes 表示页面没有变化。若全量也超预算则正常截断并附 omitted/cursor 或子树入口；截断信息不能丢失。

MCP 在初始化选择固定预设并生成 tools/list。basic 提供能力查询、授权 Space 访问、导航/观察/基本动作、断言和结果查询；testing 增加用例/测试集/报告；debug 增加获授的日志/网络；admin 增加管理。最终具体工具数量在 T115/T116 固定，不强行沿用参考文档“8/26 工具”的数量。无 listChanged 支持的客户端通过重连切换；每个工具继续独立严格 Schema，服务端继续鉴权。

## 21 知识包、修复草稿与入站兼容服务

知识包 manifest 至少有 packId/version/schemaVersion、contractVersion、origins、siteVersion、files/checksums、固定 workflowVersion 引用、变量槽与来源许可。import dryRun 返回新增/冲突/不适用/禁止内容；导入成功不代表站点动作可直接执行。用户仍需绑定测试环境/SecretRef、检查定位和发布版本；notes 不能成为新的工具指令。

locator-repairs 返回的是候选和草稿，不表示已修复业务。sourceRunId outcomeUnknown 时仍允许只读观察/生成草稿，但禁止自动续跑该写动作；历史 run 不转为成功。新草稿必须通过结构/权限/能力校验，再显式 publish 和使用独立测试数据运行。

兼容服务使用独立回环地址、鉴权和版本声明，不放在原生 `/api/v1` 下。暂定候选 POST `/health`、`/browser/list`、`/browser/detail`、`/browser/update`、`/browser/open`、`/browser/close` 共 6 条；官方固定版本与实际字段核定前不称已兼容。仅管理子集，不返回原生 ws；要求 `connectOverCDP` 直连的客户端获得明确 unsupported，转原生 SDK/受控 Worker。close/update 的状态保护不能因兼容入口而放宽，未知参数不忽略后报成功。

| 新增错误码 | 语义与处理 |
| --- | --- |
| CONTRACT_INCOMPATIBLE | 客户端/手册要求不兼容契约，返回受支持版本与迁移说明 |
| PREVIEW_ACCESS_DENIED | 无 screen.read 或页面高敏感，不返回图像 |
| PREVIEW_QUOTA_EXCEEDED | 超限，返回配额/重试建议；既有控制事件继续处理 |
| KNOWLEDGE_PACK_INVALID | 格式/路径/脚本/秘密/依赖错误，整包不应用并给出安全诊断 |
| KNOWLEDGE_PACK_CONFLICT | 版本/命名冲突，先解决差异，不覆盖发布版本 |
| LOCATOR_REPAIR_AMBIGUOUS | 候选不唯一，缩小范围或人工，不自动点击 |
| REPAIR_RESUME_BLOCKED | 原写动作 unknown 或前提不符，先查验业务结果 |
| COMPAT_OPERATION_UNSUPPORTED | 不支持路由/字段/raw CDP，返回子集能力说明 |

错误不把真实秘密、原生 ws 或任意文件路径带回。契约、夹具和生成产物由 T115–T122 验收，AT01–AT12 及边界 B33–B38 见文档 08/06；当前所有示例均未执行。


## 22 浏览器客户端与后台联动契约

新增账户/权益/节点/命令/计量读侧和原生客户端路径，完整请求/响应、错误及回执见[客户端专项第8、9节](12_浏览器客户端与后台联动开发计划.md#8-协议持久化与同步契约)。前缀保持本地`/api/v1`、控制`/control/v1`、商业`/commerce/v1`，统一注册表生成多端契约，不新增绕过ActionService的驱动通道。

| 新增本地资源草案 | 用途 | 授权/状态约束 |
| --- | --- | --- |
| GET `/account-context`；POST `/account-context/switch` | 当前主体/项目、显式切换 | 清理旧范围缓存/订阅，活动任务影响明确，不另领免费额度 |
| GET `/entitlement-summary` | 档位/政策/revision、容量/运行槽/核验时间 | 缓存非权威；无财务权不返回金额/账单正文 |
| GET `/node-status` | 设备/节点、交互用户、证书/能力 | 用户登录/节点身份分开，不返回私钥或raw CDP |
| POST `/resource-preflights` | 创建/启动前只读校验 | 不预留、不收费、不授执行权，最终准入再次校验 |
| GET `/commands/{id}` | 持久接收/接受/应用/业务/停止回执 | 同ID/hash去重，accepted不等于业务完成 |
| GET `/profiles/{id}/effective-config` | requested/effective版本和路由 | 秘密仅引用；冲突/待停机明确 |
| POST `/profiles/{id}/proxy-checks` | 有界代理连接/出口诊断 | 免费四协议，域/秘密用途校验，不提交网站业务 |
| GET `/runtime-sessions/{id}` | ready/stop/诊断或计量区间/对账状态 | non_billable无扣费，付费金额以后台为准 |
| POST `/retention-previews` | 到期保留/免费回落预演 | 只读；真正停机/分配由控制面再次确认 |
| GET `/notifications` | 主体站内提醒 | 事件/正文均检查范围和财务权限 |

统一信封沿用protocolVersion、tenantId/projectId、nodeId/bootId、commandId/requestId、profileInstanceId、assignmentGeneration、leaseEpoch、deadline、payloadHash、resourceVersionId、requiredCapabilities，并校验当前entitlementRevision/grant/路由摘要。新事件/错误纳入BR001/BR019单一契约；不由客户端传free=true或purpose=test决定额度、billingMode或ACL。

资源预检只提供观测版本下的资格判断；最终创建/启动须在事务中原子分配容量/全局运行槽，节点入队/出队/发送前再次验证。配置received/accepted/applied、进程started/stopped、网页completed/outcomeUnknown、证据uploaded、支付succeeded、费用reconciled为独立事实，不合并成success布尔值。命令先持久化再ACK，正文冲突拒绝；at-least-once不保证目标网站exactly-once。

免费客户端首次关联主体/节点分配不要求购买；有效免费grant续授不依赖付费订阅、余额或支付渠道。离线不能每设备领10份，过期grant/倒拨时间需核验；错boot/epoch/revision拒绝。付款回跳仅查询订单，权益来自可信新revision，授权私钥不上客户端；AI范围token默认无购买/续费委托/退款/调账权。

对应新增BC01–BC32及BR001–BR024见文档12，所有接口均是设计，当前无运行服务或构建结果。
