# 开发中 Web 程序的功能测试与便捷操作设计

版本：1.4。更新日期：2026-11-03。关联总体规划：v1.4。保留 WT01–WT48，补充知识包、定位修复、Space 总览及 AT 增强验收演练。

## 1 目标与使用方式

将软件作为 Web 开发时的测试操作台：输入正在开发的网页地址，方便地填写用户名密码、执行登录注册、点击按钮或其他元素、检查页面和接口结果，并保存为可重跑的测试用例。既支持用户手工点选，也支持 AI 按同一套接口操作。

用户不必先学 CSS、XPath 或编写自动化脚本。最短操作路径是“输入地址 → 选元素 → 填写或点击 → 检查结果 → 保存用例”。需要精细控制时，再展开定位器、变量、请求、断言和流程画布。

本文保留完整产品设计。当前基础动作、元素探查、流程、诊断及提取/批次已有本机实现；T067设计契约完成，测试项目管理、完整快捷操作/录制/测试集/报告等仍未完成，实际状态见文档13/26。复用总体规划中的 C++14 主程序、受管浏览器、Profile/Space、租约、流程引擎和证据系统，不增加绕过这些边界的独立测试执行器。

2026-11-03免费范围：登录/注册/元素拾取/点击/断言/录制/单步/回归/Console与Network调试及报告、AI和核心接口调用均免费。无需购买、绑卡、正余额或有效付费订阅。正常业务自动化也能使用免费资源，不通过测试标记区分收费功能；用户自配模型服务的费用与浏览器功能免费分开。

免费资源为主体跨项目/设备/节点共10份独立Profile容量，本项目默认最多10个同时运行，支持直连及已验收HTTP/HTTPS/SOCKS5/SSH；标签/Space不重复计数但共享身份。多角色在10槽内并行，更多数据任务排队，等待/失败启动不计费、不记为业务失败；新增第11份环境需容量扩展。代理测试本身免费，不要求购买代理功能；线路/托管节点供应费独立。超额并发先排队或明确购买资源，测试功能不收费。测试集声明并行/容量/协议要求，预检提供排队、调整或扩容建议，不能静默删除代理换IP。

## 2 开发测试项目

每个项目保存名称、环境地址、默认页面、测试用例、测试集、数据集、角色和结果历史。地址支持 `localhost`、`127.0.0.1`、自定义端口、开发域名及测试服务；路径可包含查询参数和 SPA hash 路由。

| 配置 | 示例 | 预期行为 |
| --- | --- | --- |
| 项目 | 示例后台管理系统 | 多个项目独立保存用例和数据 |
| 开发环境 | `http://localhost:3000` | 快速调试本机程序，检查服务是否已启动 |
| 测试环境 | `https://test.example.test` | 使用对应测试账号、变量和授权范围 |
| 页面路径 | `/login`、`/register`、`/orders` | 用相对路径组合环境地址，切换环境不改步骤 |
| 未登录角色 | anonymous | 开始前清除指定测试身份或新建临时环境 |
| 已登录角色 | ordinary-user、admin-test | 使用对应登录前置步骤与 SecretRef |
| 数据集 | 正常账号、错误密码、重复邮箱 | 每组数据单独生成 case run，结果可比较 |
| 认证入口 | `/login` | 会话过期时按用例预期失败或执行登录前置 |
| 结果标准 | URL、用户菜单、业务结果 | 至少验证业务状态，不能只检测点击成功 |

开发/测试环境有明显标识。复制用例到其他环境时，账号、地址和清理策略需要重新匹配，不把开发测试数据静默带入生产环境。

用户先自行启动 Web 开发服务。连接失败分别提示“端口未监听”“目标页面不存在”“证书错误”“后端接口失败”“前端脚本异常”或“断言不满足”，提供相关证据入口。首版不自动执行用户项目中的任意启动命令。

## 3 鼠标选元素与快捷操作

### 3.1 选取体验

点击“选元素”后，鼠标悬停高亮候选元素，并显示类型、文本、角色、可访问名称、所在区域和 frame。选取动作本身被拦截，不触发按钮提交或链接跳转；按 Esc 取消，确认执行后才进行真实操作。

选中后显示快捷操作栏：“执行一次”“加入步骤”“添加断言”“录制到用例”“查看请求/日志”。常用参数在此直接填写，不要求先打开整张流程画布。

对文本或图标内部节点，先保留原始选取节点，同时建议对应的可点击按钮或链接。重名元素展示区域和候选列表；隐藏或禁用控件明确标注，不能用强制点击掩盖实际不可操作问题。

### 3.2 首批 12 类常用操作

| 操作 | 典型目标 | 便捷行为与验证 |
| --- | --- | --- |
| 单击 | 登录、注册、保存、链接 | 点击后可关联页面变化、业务断言或请求 |
| 双击 | 可编辑表格单元格 | 明确双击次数与目标，不拆成两次未知点击 |
| 右键 | 自定义右键菜单 | 打开页面菜单并检查后续可选项 |
| 悬停 | 菜单、提示、操作栏 | 等待对应菜单/提示可见，再保存后续步骤 |
| 填写 | 用户名、密码、邮箱、搜索框 | 可使用固定值、参数或 SecretRef |
| 清空 | 搜索条件、输入框 | 清空后验证表单值，避免只模拟一个按键 |
| 按键 | Enter 提交、Tab 切换、快捷键 | 键盘输入限定当前获授权页面及焦点元素 |
| 选择 | 原生下拉框、日期选项 | 按 label/value 选择；复杂控件需要步骤组合 |
| 勾选/取消 | 协议、记住我、多选项 | 设置期望 checked 状态，不依赖盲目切换 |
| 滚动到 | 页尾按钮、懒加载区域 | 将元素滚动到可见区并重新验证定位 |
| 读取 | 标签文字、属性、表格值 | 提取为变量或查看实际结果，不改变页面 |
| 断言 | 页面文本、按钮状态、输入值 | 保存期望值并立即试验是否通过 |

上传、下载、拖拽和 Canvas 等沿用总体功能矩阵的版本与能力声明，不默认视为所有控件都能用上述快捷操作完成。

### 3.3 定位与动态页面

优先生成 test ID、角色和名称、label 等语义定位，CSS 为必要补充；显示命中数量和稳定性原因。可以复制定位、复制 API 调用、保存为页面元素对象，并批量复用。

前端热更新、SPA 路由切换和组件重绘后，立即检查文档/节点引用是否失效。允许在新快照中重新匹配稳定定位，但不能无提示点向旧坐标。iframe 和开放 Shadow DOM 继承统一的 frame/session 处理。

## 4 登录与认证测试

### 4.1 登录模板

模板引导用户依次选择：登录地址 → 账号框 → 密码框 → 可选角色/勾选项 → 登录按钮 → 成功标识 → 失败标识。生成可编辑步骤，不将元素名称写死为某个站点的 HTML 结构。

例如“填写账号 → 填写密码 → 点击登录 → 等待用户菜单出现 → 断言显示测试用户名”。密码以 SecretRef 保存；AI 日志和截图按敏感字段处理，不能通过录制器写成明文常量。

### 4.2 成功与失败判断

登录成功可由用户菜单、正确用户标识、已登录业务页和特定响应组合验证。URL 不变的 SPA 登录同样适用。仅有 200 响应、按钮消失或页面跳转不能独立作为通用成功规则。

错误密码测试应断言明确失败提示，并确认用户仍未登录。刷新后保持登录、退出后不能访问业务页、会话过期跳转或错误状态应各自成为独立用例。

### 4.3 登录前置模式

| 模式 | 用途 | 状态要求 |
| --- | --- | --- |
| 全新未登录 | 登录、注册、未授权访问测试 | 每例使用空白临时 Profile 或声明的未登录基线 |
| 每例登录 | 角色权限、稳定回归 | 在前置阶段执行登录步骤，结束后清理 |
| 复用认证 | 开发调试和只读业务验证 | 验证身份和有效期；失效时不得静默换账号 |

认证快照视为秘密状态，按环境、账号和权限保管，不跨项目自动复用。浏览器状态恢复不一定恢复服务端会话，应先验证实际用户身份。

## 5 注册与表单测试

注册模板支持用户名、邮箱、密码、确认密码、条款、多选、下拉等字段。字段和值来源均可编辑，支持人工录制或 AI 根据当前页面生成草稿。

成功注册必须验证账号创建后的页面或业务状态，不能把提交按钮可点击当作通过。负向用例覆盖空字段、格式、密码要求、确认不一致、条款未勾选及重复账号；负向测试通过意味着系统正确拒绝了请求。

注册数据由数据集生成唯一后缀，记录本次创建的资源，避免第二轮因重复账号失败。重复账号用例则显式引用预置测试账号。注册/创建结果未知时先查询结果，不能自动重复提交。

邮件、短信和 MFA 优先使用开发程序提供的测试邮箱、测试通道或受控测试接口。没有配置通道时进入等待人工，并将无人值守执行标为受阻；不能伪造验证成功或绕过验证逻辑。

## 6 断言编辑器

选中元素后可以选择“添加断言”，设置期望值并点击“立即验证”。编辑器显示当前值、期望值、定位命中数、超时和失败原因；提示该断言是否能够判断业务结果。

| 断言 | 用途 | 示例 |
| --- | --- | --- |
| 文本/提示 | 成功或错误信息 | 出现“密码错误”，用户菜单仍不存在 |
| URL/路由 | 登录跳转、页面导航 | 路径为 `/dashboard` 或 hash 满足预期 |
| 存在/可见/隐藏 | 弹窗、表单错误 | 注册错误提示可见，成功页未出现 |
| 启用/禁用 | 提交限制 | 条款未勾选时注册按钮禁用 |
| 值/选中状态 | 输入、下拉、协议 | 邮箱值正确，协议 checked 为 true |
| 元素数量 | 列表和搜索结果 | 新增前后目标行数量差为 1 |
| 业务响应 | 页面操作对应接口 | 指定接口业务码为 success，响应角色匹配 |
| 认证状态 | 登录/退出 | 用户标识正确；退出后受保护页不可访问 |
| 未出现异常 | 稳定性辅助 | 本步骤没有新增未允许的 Console error |

预期请求的观察器在点击之前注册，防止漏掉快速响应；同时核对方法、origin、路径、run/step 和请求相关特征。不能把另一个标签或后台轮询的同名接口当作本次操作结果。

断言支持受限组合 all/any。出现多次重试时保留每次结果，最后成功也显示首次失败，不把不稳定用例悄悄标成稳定通过。

| WT42 | 响应式与触摸仿真 | 桌面/窄屏视口、DPR 和触摸参数 | 控件布局和操作符合夹具预期，报告注明仿真环境 |
| WT43 | Canvas/OCR 候选 | 固定 Canvas 文本、重叠目标和过期截图 | 正确候选可确认，歧义/低置信度/布局改变不盲点 |
| WT44 | 认证代理中断 | per-Profile 转发器、DNS/IPv6 探针，运行中停止桥 | 浏览器失败且无静默直连，支持范围和限制可查 |
| WT45 | MV3 扩展版本 | 两个环境分配不同版本的测试扩展 | 版本/权限不混用，缺失加载能力有明确结果 |
| WT46 | 备份恢复反例 | 停机快照、错误口令、篡改包、磁盘不足 | 正确副本可恢复，错误副本拒绝且不破坏原数据 |
| WT47 | 更新签名与失败回滚 | 测试签名制品、篡改/过期/降级元数据和安装失败 | 不可信更新拒绝；受控失败恢复程序与匹配数据版本 |
| WT48 | 已提交但响应丢失 | 夹具保存业务后断连接，同时停止/重启服务 | 不重复注册/保存，状态 unknown，核对后才继续或补偿 |

WT44–WT48 为环境与故障集成夹具，不需要真实第三方业务账号。某个用例按测试目标预期返回 unsupported/blocked 可以是反例通过；这与未配置必需组件导致整个用例 blocked 不同，报告须区分。

这 48 项是可重复的发布基准，不穷举全部边界。API/租约竞态、超大消息、磁盘/进程、DST、跨版本和权限另有契约与故障集，逐项对应 B01–B38，不能用 48 项通过取代这些验收。

WT18 在回归中自建前置数据，不依赖另一个用例恰好先执行。WT24 的每种故障作为该用例的数据参数生成独立结果；故障用例应准确判定预设失败，不能造成整个回归误判全通过。

## 8 测试数据 前后置与隔离

用例由前提、数据、动作流程、断言、清理及执行策略组成。动作仍调用现有 workflow 版本，测试层负责按项目和数据集包装，避免新增另一套点击/等待实现。

数据支持固定值、内联参数、SecretRef 和唯一值生成器。字段有类型、必填与敏感标记；运行输入快照记录使用的版本，但秘密只记录引用。每例的随机种子与唯一后缀可追溯。

前置和清理可以使用项目明确配置的页面动作或测试专用接口。清理只操作本次记录的资源；超时、失败和人工取消均要尝试允许的清理，并保留清理失败状态。清理失败可能污染环境时，阻断后续依赖用例，不能以主步骤成功覆盖该问题。

测试邮箱、一次性账号和角色状态不跨并行用例混用。共享 Profile 遵循单写入租约；需要真正并发的用例使用独立 Profile 和独立后端测试资源。浏览器隔离不意味着后端数据库隔离。

## 9 测试集 调试与报告

### 9.1 运行入口

支持“执行一次当前动作”“单步运行”“重跑当前用例”“运行选中用例”“按标签运行”“回归整个测试集”。参数化测试按每行数据展示结果，并可暂停、接管、取消或展开失败步骤。

仅重跑失败用例时创建新 attempt，记录原失败和本次使用的代码版本/环境/数据，不覆盖历史。登录、注册和数据写入按声明前提重新准备，不能直接沿用上一轮已改变的页面。

### 9.2 结果状态

| 状态 | 语义 | 报告处理 |
| --- | --- | --- |
| passed | 动作与全部断言通过，必要清理成功 | 计入稳定通过 |
| failed | 已知动作、业务或断言不符 | 显示期望/实际与证据 |
| blocked | 服务不可达、缺凭据、人工验证或污染环境阻断 | 单独统计；不能算通过 |
| skipped | 根据明确筛选或依赖策略未执行 | 记录原因；不能掩盖阻断 |
| flaky | 相同条件下失败后重跑成功 | 独立标记，保留所有 attempt |
| outcome-unknown | 写入可能发生但无法确认 | 停止重放，先核对业务状态 |
| cancelled | 用户或运行策略终止 | 保留已完成步骤与清理结果 |

测试报告至少显示项目、环境、浏览器/应用构建版本、用例版本、角色、数据集 ID、开始结束时间、结果分母、断言期望/实际、截图、定位、Console/请求关联和清理状态。

支持 HTML 供开发者阅读、JSON 供工具处理、JUnit XML 供 CI 对接。JUnit 对 blocked/取消/未决状态的映射必须保留原始状态和原因，并用非零退出码阻止“全部成功”的误判。

### 9.3 调试便利性

点击失败步骤可查看当时页面、元素与请求，再选择“重新定位”“修改参数”“修改断言”“进入页面手动操作”。修改后生成新草稿；历史运行保留原用例版本。

对于 AI，返回精简失败摘要和证据引用，允许按需展开请求或快照。AI 可以建议修复定位或测试步骤，修改网站源代码仍由项目开发流程处理，不能把改了断言以让测试变绿当作修复业务缺陷。

## 10 AI 与命令行调用

AI 可以接收“测试本地网站的注册功能，再用新账号登录”的任务：读取页面 → 指认字段与按钮 → 生成可审阅用例 → 使用测试数据执行 → 检查业务结果 → 输出失败原因与证据。允许明确指定要点击的按钮、区域、顺序和预期结果。

新增工具围绕 `web_test_projects`、`browser_inspect_element`、`browser_assert`、`web_test_validate`、`web_test_run`、`web_test_status`，仍通过原有动作服务与租约。页面包含多个“提交”按钮时，必须要求缩小区域或返回候选，不能按猜测继续。

CLI 可从终端或 CI 触发固定测试集，提供环境、标签、数据集、报告路径、超时和退出码。无 UI 的触发不等于浏览器可在任何无桌面环境运行；Windows 交互式浏览器和需要人工验证的用例分别声明运行要求。

## 13 参考文档补充后的开发测试体验

开发者仍从“输入 localhost/测试域名 → 选字段与按钮 → 填写/点击 → 加断言 → 保存用例”开始，不必先理解矩阵、SDK 或安装知识包。普通账号密码登录和表单注册无需模型、容器/Java、邮件服务或 OCR；仅用例引用相应增强能力时检查其配置。

环境矩阵帮助定位“开发/测试用错地址、语言/时区声明未生效、代理出口不符、环境版本不同”，展示事实与证据，不输出账号风险评分。Space 总览同时看多个测试角色/Profile 的进度和待人工项；同 Profile 仍共享身份，双账号并行用不同 Profile，不能因为两张卡片就认为隔离。

定位失效时，失败页提供“对比快照 → 查看候选 → 高亮确认 → 保存修复草稿 → 重新验证/发布”的顺序。HMR 替换节点后旧 ref 拒绝；候选多于一个时缩小区域，不能自动选第一项。注册已到达服务端但响应丢失时，先查询本用例资源是否存在，不因定位修复重新提交；旧失败/unknown 报告保留。

成功的登录、注册和按钮用例可以另存站点知识包，包括字段定位、已知提示、固定流程及变量说明。导入到另一项目后重新绑定环境/测试凭据并校验定位；包不携带账号、Cookie、验证码或任意脚本。站点版本和 UI 语言变动时显示适用性失效，不自动沿用旧预期。

TS/Python 薄客户端与 MCP/CLI 共用契约及业务服务，适用于开发者把已发布用例接到自有 CI。Agent 选择 testing 工具集后可获取精简步骤、差分快照和报告，再按需展开证据。SDK 不自动重复 unknown 写入，客户端版本不匹配给出明确诊断。BitBrowser 入站服务只兼容核定管理子集，旧脚本依赖原生 ws 时须迁移，不影响本项目原生测试功能。

## 15 后台联动后的浏览器测试与便捷操作

本轮按[客户端专项](12_浏览器客户端与后台联动开发计划.md)补齐BF18/BF19与BR011/BR019，保留“输入测试地址→选元素→填写/点击→断言→保存/单步/回归”的默认路径。账户/全局槽首次免费关联在入门处理，选元素页面不要求先购买、配置模型、填写账单字段；普通登录注册无需可选邮件/OCR/IdP组件。

| 测试操作 | 客户端/后台联动行为 | 证据与失败处理 |
| --- | --- | --- |

| 远端执行 | 明示localhost指执行节点；需本机程序时选本机节点或配置受控可达测试地址 | 不自动暴露本机端口/建隧道；地址不可达为blocked并给网络诊断 |
| 测试数据与前后置 | 任务包绑定数据命名空间/凭据槽、唯一输入、固定前后置版本 | 清理失败污染阻断后续，中央不保管网站明文密码 |
| AI/CI/外部软件 | 范围token通过相同Local API/SDK/MCP/CLI，费用功能免费 | test用途不绕ACL/容量；AI默认无购买权，模型账单独立 |
| 查看/接管/调试 | 权限预览、Console/Network/步骤/证据，本机交接确认后显示ready | 预览非远程桌面，Session0不可冒充桌面，旧代所有写入口拒绝 |
| 报告与费用 | 测试结果/证据上传与资源计量分列 | 自有节点免费non_billable、费用0；主动选择托管资源才按明示资源合同计费 |

后台或商业页更新不能把免费测试变成限时试用，也不能把支付渠道故障当作免费测试欠费。控制服务无法续授时显示连接/授权待核验，按有限grant保存结果/受控停止，不诱导付款；付费资源到期可选择10份保留回落，合规代理不变，业务unknown不因续费重新运行。
