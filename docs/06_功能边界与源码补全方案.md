## 2 平台、运行时与接口

### B01 C++14、GUI 与基础库

自有工程采用 VC++2019 / VS2019 16.11 / v142 / x64，首轮 SDK 10.0.19041.0，Debug/Release CRT、依赖语言标准和实际编译参数逐目标验收。工具链清点不是编译通过；CMake/ABI/编码与替代门见文档 09。现有 UTF-8 无 BOM、LF 文档保持原格式，遗留源文件不得默认转码。

首选有明确补丁和分发来源的 Qt 5.15 Widgets，使用 QGraphicsScene 自建流程画布。Qt 6 主线不能直接作为 C++14 依赖；现代节点编辑器也须检查最低语言版本。没有可接受的 Qt 维护来源时，采用 Win32 壳和同一 C++14 Core，并在 G0 调整 UI 工作量，不固定旧 QtWebEngine 承载网页。

JSON 首选 R02；Schema 首选 R03，限定 JSON Schema draft-07 的已支持子集。传输首选对应 Qt Network/WebSockets；Win32 路线使用 R01 的 C API 提供受限 REST/WebSocket，TLS 和依赖按版本锁定。禁止直接使用“最新版头文件”后允许编译标准自动升级。验收：自有目标全部 `/std:c++14`，Debug/Release 构建，最小 JSON/Schema、中文/大消息、取消和 TLS 错误测试。任务 T003/T004/T077/T089。

### B02 浏览器下载、版本与协议能力

RuntimeManager 管理来源 URL、版本、平台、下载大小、哈希、可验证签名、安装目录和许可记录。CfT 版本索引用于发现官方构建，下载源及重新分发条款另外检查；没有可信签名/哈希依据的制品不能仅因 HTTPS 成功就标为已验证。优先用户指定受支持运行时，自动下载为可选管理能力。

下载先落临时目录，校验归档条目、大小与路径后原子激活；中断可重试下载，不能重试业务动作。启动以 Browser.getVersion 和能力探测决定支持表。至少验证发布时选定的两个浏览器版本；回滚程序不自动降级已迁移的 Profile，必要时恢复升级前副本。断网、磁盘满、压缩包损坏、协议字段变化均有可见错误。任务 T006/T078/T094。

### B03 Profile、进程与磁盘生命周期

一个 Profile 只有一个浏览器数据目录和一个受管实例。配置变更采用 revision；代理、扩展等需重启的配置进入 pending，启动后记录 effective。通过 Job Object、进程路径、启动时间和随机实例标记确认归属；PID 复用或握手失败时先隔离，不误杀其他浏览器。

禁用对运行中 Profile 的裸复制；归档、恢复、删除和清理都有引用检查与目录句柄校验，处理 junction、符号链接、UNC、长路径、中文路径及磁盘满。崩溃后先读运行日志再决定接管/停止；持有未知写结果的 Profile 不自动投放新任务。任务 T015–T017/T055/T093/T095。

### B04 CDP、REST、MCP 与本机权限

自有 C++14 CDP Router 区分 browser/target/frame session，维护 commandId、会话代数、超时与有界队列。优先验证 CDP pipe，WebSocket 为兼容路径；端口只有回环绑定仍不能视为本机用户隔离。使用受控子进程句柄、每用户服务、命名管道 ACL 和最小文件权限；威胁边界不包含同用户管理员或已被攻陷的宿主。

API 拒绝错误 Host/Origin、越权资源、超大 JSON 和过期租约。GET 列表游标分页，PATCH 使用 If-Match；请求重放绑定主体、资源和正文哈希。事件保留窗口过期返回 EVENT_CURSOR_EXPIRED，客户端重取快照。MCP stdio 实现协议协商、取消、工具 Schema；HTTP 另按 T108 交付，不能把本地 SSE 当成 MCP HTTP。任务 T018/T021/T030/T077/T079/T097。

### B05 身份、Space、控制权与并发

Profile 才是 Cookie、站点存储和浏览器进程的强隔离单元；同 Profile 不同 Space 仍共享登录态、Service Worker 和同源存储。默认每 Profile 一个自动写入者；只读操作也要限定标签与数据权限。租约 token 的 generation 在入队、出队、发送前核验，接管同时吊销录制回放、同步、调试写入、网络规则、脚本 Worker 和外部适配器写路径。

弹窗继承 opener 的空间和域权限，未知来源新标签进入隔离区。取消只停止尚未派发步骤；已经提交的请求不因 UI 显示停止而消失。验收包含双客户端竞争、队列延迟中接管、控制服务重启、后台焦点及同 Profile 注销互相影响。任务 T024–T026/T040/T079/T095。

## 3 元素操作、录制与认证测试

### B06 元素拾取与操作录制

拾取模式使用 CDP Overlay/inspect 能力与隔离世界事件采集；框架切换、OOPIF 和开放 Shadow DOM 建立独立注册。默认捕获 pointerdown、click、keydown 的选择意图并阻止业务派发，Esc 退出；页面已经收到更早监听事件的情况须由 WT19/WT25 的后端计数验证，无法可靠阻止时切换为静态截图选取并提示重新观察，不能继续声称“零副作用”。

参考 Playwright recorder 的定位器与动作合并设计，建立 click/input/change/submit/IME composition/drag 导航事件序列。程序回放事件不能被再次录成用户动作；密码、隐藏 token、剪贴板默认不录正文。rrweb 仅作为可选的脱敏浏览证据，不承担动作回放、事务撤销和后端恢复。任务 T038/T044/T069/T080。

### B07 定位、文档失效与跨框架

引用包含实例、空间、target、frame、session、documentEpoch、backendNodeId；路由更改和局部重渲染不能简单等同整页导航，也不能延用已脱离节点。定位候选保存 testId、role/name、label、区域和唯一性检查；同名、虚拟列表复用节点、隐藏副本不取第一项。

OOPIF attach/detach、BFCache、prerender 激活及 SPA 路由变化均使相应上下文重新验证。开放 Shadow DOM 支持深层定位；关闭 Shadow DOM、浏览器内部页和受保护内容按驱动返回 unsupported，允许站点测试钩子或人工接管。参考 Playwright 的 chromium/frame/injected 源码，不把 ego 公共接口说明当作跨框架完整实现。任务 T010/T027–T029/T080/T099。

### B08 复杂控件、弹窗与浏览器事件

12 类快捷动作之外补充原生对话框、弹窗归属、拖放、contenteditable、组合输入、SPA 导航、beforeunload 和文件选择。JS alert/confirm/prompt 在动作前订阅并按用例策略处理；popup/download/navigation 等期望事件也必须先注册观察，再发动作。每项返回 dispatched/verified/outcome-unknown，明确 click 事件成功和业务断言成功的差别。

日期控件、React/Vue 受控输入、自绘下拉和跨框架拖放按控件夹具验收；不可用时要求适配规则。系统证书选择、浏览器安装提示、操作系统文件窗口不作为后台 DOM 控制保证。权限按 origin 单独设置，结束恢复；需要人工的步骤在 CI 返回 blocked。任务 T019/T046/T070/T081。

### B09 登录、注册、会话与多角色

登录前置是“新身份 / 指定账号登录 / 同角色受控状态”三种；状态复用带账号、租户、环境、存储版本及有效性检查。Cookie、localStorage、IndexedDB、sessionStorage、分区 Cookie/CHIPS 和 Service Worker 分别声明覆盖范围，不能把通用 storageState 当成完整磁盘镜像。过期状态要重建，不能忽略失败后继续后续用例。

注册使用 run/case/attempt 唯一标记；后端确认账号恰好创建一次。注销、刷新、跨标签、CSRF、跨域跳转、SameSite、429 限流、角色和租户隔离都要核对预期。后端查验、清理 API 使用测试端专用凭据和作用域；UI 按钮不可见不能证明服务端授权正确。任务 T068/T070/T072/T083/T085/T098。

### B10 邮件、短信、验证码与密码重置

邮件首选 R06 Mailpit 的 SMTP 测试收件箱及 HTTP API；按 case 独立收件人、发送时间、关联 ID 过滤，再读取验证码或激活链接。超时、重复、乱序、失效、重发和旧验证码不接受均有用例。链接必须再次校验允许域，正文和验证码仅作为敏感短期数据。

短信不自建真实运营商集成，定义 MockInbox HTTP 契约，由开发中的后端把测试短信写入隔离收件箱；可用 R08 模拟供应商回执，真实短信服务仅经用户配置测试账号接入。CAPTCHA 使用站点官方测试 key、开发环境测试开关或人工接管；不承诺自动破解。该测试开关须与生产构建隔离。任务 T082/T099，覆盖 F53。

### B11 OIDC/SSO、MFA 与 Passkey

R07 Keycloak 独立运行作为受控 OIDC 身份提供者，先覆盖 Authorization Code + PKCE、state/nonce 错误、回调取消、过期和租户不匹配；SAML、企业设备条件访问、第三方账号恢复不计入首版兼容承诺。跳转链每一目标都经过域授权，不把任意 IdP URL 自动放行。

TOTP 只用测试账号种子并保存在 SecretRef，覆盖时钟偏移、过期及重放。WebAuthn 使用 CDP 虚拟认证器创建测试凭据，结束销毁并记录目标 origin；它只验证 Web 流程，不替代真实硬件、系统 Hello 或设备绑定测试。外部真实 MFA/推送等待人工；无交互 CI 返回 blocked。任务 T083/T099，覆盖 F54。

## 4 调试与测试增强

### B12 Network、Mock、HAR、WebSocket 和 SSE

CDP Network 负责观察，Fetch 负责限定范围的拦截。每条 mock 规则绑定 test run、origin、method、资源类型、最大命中次数和有效期；异常退出撤销。默认只读记录，不因打开 Network 面板就启用拦截。暂停请求有截止时间和明确失败策略，禁止规则过期后静默把本应 mock 的写请求发送到真实服务。

R08 用于独立测试后端；Playwright Worker 用于复杂路由/HAR 回放。请求重定向链、Service Worker、缓存、CORS、二进制正文和流式响应分别记录限制。HAR 是脱敏 HTTP 证据，不是所有协议的完整可重放快照；WebSocket/SSE 先提供消息观察和限量断言，消息级故障模拟只在测试服务/Worker 的已验收能力下开放。mock 结果必须带 provenance，不能冒充真实集成测试。任务 T039/T071/T084/T107，覆盖 F55。

### B13 可重复时间、随机数与测试数据

通过测试站点钩子或 Playwright Clock 控制页面时间与 timer；不能假定同时改变 TLS、OS、后端和 Worker 时钟。随机数固定仅用于声明的测试夹具，不替换安全随机源。倒计时、token 过期、跨日、DST 使用明确时区和后端测试时钟。

准备和清理使用 tenant/run 命名空间，记录创建资源 ID，依赖关系逆序清理；共享资源采用租用池和互斥锁。清理失败将环境标为 contaminated，阻止后续依赖。服务启动命令、容器和 reset API 均为用户配置且有超时/端口检查；不执行网页提供的宿主命令。任务 T072/T085/T090/T098，覆盖 F58。

### B14 视觉回归与基线审阅

R09 Pixelmatch 独立 Worker 对截图计算差异，返回差异像素数、占比和 diff 图。per-pixel threshold 与整图允许差异比例是两个参数；不混为“相似度”。固定浏览器/字体/系统、viewport、DPR、主题、语言，等待字体与动画稳定，声明遮罩和截图范围。

基线必须由用户审阅新建版本，不在失败后自动覆盖。尺寸不同、缺基线和环境不一致返回 blocked 或明确配置错误。视觉匹配不证明登录、提交或服务端数据正确，需与业务断言组合。任务 T086/T099，覆盖 F56。

### B15 无障碍、响应式与移动仿真

R10 axe-core 在目标测试页运行固定规则集，报告 violations/incomplete/inapplicable 与 frame 覆盖范围；无法自动判断的项保留人工检查。它是测试页的可选扫描器，不是让桌面工作台自身无障碍验收自动通过。

提供桌面/窄屏 viewport、DPR、触摸、颜色偏好与媒体特征矩阵，验证横向溢出、焦点顺序、Tab/Enter/Escape 和语义按钮。Chromium 移动仿真不等于真机、iOS Safari、原生 App 或微信内核；真实设备为独立实验室适配。任务 T087/T099，覆盖 F57/F44。

### B16 Canvas、OCR 与视觉动作

优先站点 test hook 和可访问替代层；无 DOM 语义时，用截图 ArtifactRef 调用 R11 Tesseract 外部进程，获取文本、置信度和框。中文 traineddata、图像处理依赖分别固定许可与哈希；当前 OCR 引擎构建标准高于 C++14，不链接进主程序。

OCR 只能提供候选，不证明元素身份。坐标动作绑定截图、视口、DPI、滚动位置和过期时间，重叠候选、低置信度或页面改变则重新观察/人工选取。首版支持固定 Canvas 测试夹具，不承诺任意网站视觉 Agent；可选远端视觉模型须显示数据去向与预算。任务 T088/T099，覆盖 F59/F20。

### B17 流程画布、版本和导入

自研 C++14 QGraphicsScene 画布映射相同 DSL，支持节点、端口、连线、缩放、撤销、复制粘贴、键盘删除和自动保存草稿。R20 nodeeditor 提供 Qt5/C++14 构建分支，可在 T077/T042 验证后有限复用；默认 Qt6 配置需显式改为 Qt5。xyflow 可作交互参考或后续外部 Web UI。循环必须为显式节点，不能任意连成无界图。

导入时检测未知节点、孤立节点、递归子流程、变量类型、权限、秘密引用和版本。执行只读固定发布版本及哈希；撤销编辑不撤销网页动作。大图以 200 节点夹具衡量交互，性能不达标先做折叠子流程。任务 T033/T042/T043/T089。

### B18 表达式、Schema 与调度

首版表达式为自有小型 AST：字面量、字段路径、比较、布尔、有界算术和固定字符串函数；禁用 eval、文件、网络、反射与递归，限制深度、字符数和执行预算。正则只开放已限定输入/模式，不能让不受限正则阻塞服务线程。R03 draft-07 validator 不代表支持 2020-12；OpenAPI 3.0.3 的模型通过显式转换生成，不与内部 Schema 方言混用。

R04 提供日期/时区基础，自研调度器定义春季缺失时刻 skip、秋季重复时刻 first-only 的默认策略，用户可另选。触发键由 scheduleVersion + 本地计划时刻 + UTC offset 构成，落库去重；休眠/重启按 skip 或一次补跑，禁止无限补跑。页面测试时钟不能控制调度服务时钟。任务 T033/T048/T089/T090。

### B19 AI、脚本与来源不可信内容

AI 只生成可审阅 DSL，所有输出通过 Schema、能力与预算检查。页面、邮件、OCR、日志均为不可信数据，不能提供新的宿主权限。页面脚本仅在授权 origin 的隔离上下文运行、限时、限返回大小；并不自动拥有 Node/fs 权限。

首版不运行任意用户 Node 脚本；可选 Playwright Worker 为受信产品组件，通过受限桥接领取动作与结果，不能私自连接全权 CDP 后继续宣称租约完全有效。独立进程和 Node vm 都不构成恶意代码隔离；未来开放脚本插件须使用受限 OS 账户/容器或 VM 并单独验收。任务 T025/T049–T051/T079/T089。

纯 OCR/图像比较 Worker 不接触 CDP。确需 Playwright 的浏览器能力时，只允许固定版本的受信代码，经服务端 CDP 代理连接指定 Profile/targets；不发原始浏览器调试地址。每条可能写入的协议消息都校验租约代数，Runtime.evaluate 默认按写处理；限制 target/frame/origin、事件大小和连接数，禁止 Worker 自建绕过通道。Worker 不接受网页或模型传入的任意 JS；不能证明消息门禁覆盖的功能先禁用或交还自有 CDP Driver，T097/T100 以接管期间的实际协议日志验收。

## 5 环境管理与交付

### B20 代理、认证、DNS 和网络失败

原生 HTTP CONNECT 和无认证 SOCKS5 先交付；需要认证时，以 R19 GOST 作为独立、仅回环的 per-Profile 转发器候选。秘密通过受保护配置传递并及时移除；转发器退出使浏览器请求失败，不能自动直连。

HTTP、HTTPS 上游、SOCKS5 认证、IPv4/IPv6、远端 DNS、本地域绕过、WebRTC、QUIC、代理故障分别测。Chromium 代理并不覆盖所有 UDP/WebRTC 路径；特定配置需关闭非代理传输，或经用户配置网络/系统策略约束。无法证明约束时返回 supported-with-limitations；不宣称具备系统 VPN 级隔离。任务 T036/T054/T091。

### B21 高级指纹与内核构建

F06/T101–T102 首选研究 fingerprint-chromium 的固定源码与对应构建；不把晚发布源码、第三方二进制或“仓库 BSD”直接当成可分发内核。表面 JS override 不能替代 Canvas/WebGL/字体/音频/Worker/Client Hints/WebGPU 的一致性。

继续门：二进制—提交—构建脚本—补丁—许可证能对应，团队具备持续安全合并能力，且固定测试站点一致性通过。失败则保留普通 Chromium 的环境仿真与配置检测，不显示高级指纹已生效。目标是受控测试和身份环境配置，不承诺任意网站无法识别。后续独立预算见任务表。

参考源 v2.0 的自有内核工程补入后续 KG0–KG4：来源/补丁台账、构建/对照、补丁特定负测试、升级/CVE、符号签名与产品化。T101/T102 仅是 28 人日可行性/验证与有限适配，完整生产线和持续维护另行估算，不占本地 29 周。现代 Chromium 不要求由 VC2019/C++14 编译；如要求内核新增源码也完全 C++14，需重新限定路线。细节见文档 08 第 13 节。

### B22 扩展、浏览器权限与原生消息

以选定运行时的真实加载策略为准，先支持本地开发用 MV3 扩展；不能假定品牌 Chrome 的命令行加载开关、商店安装和普通 Chromium 完全相同。记录 ID、来源、哈希、版本、权限和更新策略；扩展变化使相关测试基线失效。

覆盖 content script、background service worker、扩展弹窗、incognito 和页面权限。扩展可能获得超出 Space 的 Profile 级能力，必须在环境授权时声明。Native Messaging host 是宿主可执行程序，仅允许已登记、签名/哈希核验且架构匹配的自有适配；不自动安装网页请求的 host。任务 T053/T092。

### B23 文件、下载、剪贴板与系统窗口

上传只接受用户选择或授权 ArtifactRef，校验真实路径、类型和大小；下载先订阅事件、落隔离暂存目录、校验完成与哈希，再导出。处理同名、路径穿越、符号链接、取消、磁盘满及多文件。剪贴板默认虚拟化或禁用，系统剪贴板需要单独权限；密码和敏感字段不进入录制。

浏览器文件输入使用 CDP/驱动接口，不能靠后台全局按键操纵任意系统窗口。证书、系统 Hello、打印和安全桌面优先人工；R16 UI Automation 仅为后续具名窗口适配参考，不能扩展为任意桌面控制。任务 T046/T049/T081/T098。

### B24 Console、Debugger、性能与追踪

Console、Runtime exception、Network、截图与步骤通过 run/step/request/target/frame/session 关联；不是每个并发请求都能确定属于唯一点击，因果不确定须标明 confidence。正文默认限量、脱敏、按需获取；WS/SSE 截断提供计数和丢失标记。

R17 OpenTelemetry C++ 可选输出本地 spans/metrics；离线 JSONL 是默认，外发遥测需要用户配置。v1.0 提供 scoped DevTools 诊断入口；完整断点、source map、性能 trace 分析和重放放在 T107。附加原始 DevTools 可改变页面并绕过动作代理，启用时暂停 AI，退出后重新观察并获取租约。任务 T039/T060/T096/T107。

### B25 凭据、备份、迁移与恢复

本机秘密用 DPAPI；可迁移备份采用 R05 的成熟 AEAD/KDF，包含格式版本、随机 salt/nonce、KDF 参数、加密清单、长度和认证标签，不能自创加密算法。秘密默认不导出；显式可移植备份由用户提供独立口令，忘记口令不能恢复。明文临时文件、日志和 crash dump 另做清理与脱敏。

SQLite 使用 backup API/一致性快照，浏览器数据需停机或受支持的导出路径。恢复先验真再解包到新目录，路径/大小限额、版本与磁盘空间预检，失败保留原目录。应用数据库降级不能依靠简单逆向 SQL；不兼容时恢复升级前快照。加密 Cookie、Passkey 和 App-Bound Encryption 不保证跨机器/账号迁移。任务 T049/T055/T093/T103。

### B26 安装、更新、签名与依赖供应

R13 WinSparkle C API 为 Windows 更新候选，Ed25519 验证更新包，操作系统代码签名另做 Authenticode 核验；两者用途不同。借鉴 R14 的防降级、过期元数据和密钥轮换边界，不把仅有 appcast 签名声称为完整 TUF。程序、运行时、Worker、扩展和 Schema 分别版本化。

分阶段下载—验证—停止派发—保存快照—安装—启动自检—确认，失败回到上个程序版本；数据迁移不兼容则按 B25 恢复。离线包、便携路径、无管理员安装、代理下载和证书失败均测试。不得在任务执行中强制热替换浏览器。任务 T061/T065/T078/T094。

## 6 后续能力的明确边界

### B27 BitBrowser 与 ego 适配

BitBrowser 只对指定客户端版本的健康、环境列表、开/关、CDP 和已验证配置字段交付；配置更新必须比对客户端真实生效结果。ego 通过用户安装的 native bridge 和公开 runtime 接入，公共 MIT 仓库不提供完整浏览器本体，缺失能力返回 unsupported。外部客户端关闭、版本不配、已有人工控制权和 API 鉴权错误均进入契约测试。

默认使用自有 Chromium Driver；适配失败不自动把同一身份换到另一浏览器。仅能检测本程序发出的控制，外部产品和第三方 CDP 客户端可能绕过租约；因此独占控制须以适配器真实能力声明。任务 T059/T104。

### B28 内嵌浏览器与日常浏览 UI

T105 采用 R15 WebView2 Win32 COM 做单独 POC：C++14 编译、数据目录、CDP 方法、下载/权限、代理、扩展、键盘/IME、DPI、屏幕阅读器、崩溃重建、运行时分发。WebView2 Sample 的许可不覆盖 Microsoft Runtime；Evergreen 与 Fixed Version 各有更新责任。

不能通过 SetParent 把独立 Chrome 窗口当成受支持嵌入。内嵌差距由能力表暴露，若不能满足测试/扩展要求则继续使用独立窗口。T106 另建设标签栏、地址栏、历史、书签、下载、权限和用户手动浏览模式；当前 CEF 包装层的 C++20 冲突保持隔离，只有独立进程桥可另评估。

### B29 团队、共享与远程 Worker

T109 采用 Keycloak/OIDC 作为身份候选，服务端自研 tenant/member/role、资源 ACL、审批策略及审计。分享的是有版本配置/受控状态包，不能多人同时写同一 Chromium 目录；Profile 独占租约保存在服务端事务存储，执行节点在入队、出队及派发前检查 generation/epoch，收到吊销或到达本地授权期限后停止新写。中央心跳超时不能证明旧节点/浏览器已停止。

T110使用mTLS Worker身份、任务固定版本和能力清单；心跳不等于业务执行成功。网络分区只重派尚未执行或已确认幂等任务，未知写结果冻结人工核对。远端localhost是Worker自己，不是开发机；开发隧道和端口暴露需单独配置。T111包含审计、密钥轮换、备份恢复及远端证据保留。云手机/设备农场仍单列，但自身环境销售、计时、续费、席位和单部署商业托管现已纳入文档11，不能继续按原“商业以后再做”处理。

详细范围、MF01–MF36、ADM001–ADM048、BT01–BT36 见[管理后台专项](10_管理后台功能与开发计划.md)。中央只保存凭据槽元信息，网站/代理/模型秘密保留执行节点；配置定义与物理实例分开，同一身份不凭心跳超时自动跨机双开。首版 Web 提供只读预览、受控 Console/Network 查询和本机人工交接；元素拾取/录制复用桌面客户端，完整 Web 画布和远程键鼠另列。恢复旧中央备份进入对账模式并更新协调代数，不复活旧 lease/outbox。

原T109–T111的75人日由ADM252基线/282–302计划替代，不重复相加；新增COM223基线/258–278计划，完整后台475基线/540–580计划人日。ADM20周仅并行目标，COM另设24周目标，均需资源排程；不能把商业增量塞入原20周。当前ADM串行最长链104有效工作日，具体截止不由总FTE容量直接推定。

商业边界见[环境销售计费与商业运营计划](11_环境销售计费与商业运营后台计划.md)：同实例人工/AI/RPA按区间并集记录，独立实例分别计；免费诊断区间为non_billable，不扣钱或已购/赠送时长，只有明确约定的付费资源按报价计费。权益/资源ACL/控制租约同时有效，所有打开/调用入口统一校验。支付unknown查渠道、计量unknown有界预留后对账、业务unknown不盲重试，三者不能共用一个成功标记。付费到期/欠费停新增付费消耗并保留数据，基础免费权益不失效；有限保护窗口不撤销网站已发生动作，退款/账本冲正和权益回收各有确认。命名席位、设备、并发、环境容量与时长互不代替。托管回收需停止确认和租户数据清理证据，离线客户端签名不等于不可篡改计量。

免费边界：持续免费10环境、RPA/Local API及HTTP/HTTPS/SOCKS5/SSH接入，AI/测试/核心接口继续免费。主体全项目/设备/节点持有容量10、本项目默认运行槽10；模板/草稿不计，独立克隆另占、可恢复归档占额、停止确认且彻底删除才释放，标签/Space不倍增。免费自有节点无需订单/余额/订阅，代理功能不触发付费；超额容量/并发或明确选择额外托管资源才收费，purpose=test不绕额度/ACL。服务端/节点校验代理实际路由、凭据槽和驱动能力，合法配置允许使用；系统/PAC/环境来源不静默继承，失败不静默直连。HTTPS代理/SSH隧道、host key及桥故障由COM014/ADM030衔接基础T091验证，缺能力返回不支持而非免费需升级。跨节点抢容量/槽原子化，未知停止不回收；到期选择10份环境/默认10会话回落并保留合规代理，租用资源期限单列。FG与COM追踪按最新政策，历史研究证据不改写。

### B30 macOS、Linux 与平台能力

T112 将进程树、窗口管理、凭据、证书、浏览器路径、文件权限、安装与签名提取为平台接口。macOS 使用 Keychain/签名与公证，Linux 凭据服务按部署环境选择；缺失安全存储时不静默明文。跨平台先运行同一夹具和 API 契约，再决定发布范围。

Windows Job Object、DPAPI、COM 和窗口同步实现不直接复用到其他平台；Wayland 的窗口控制、headless/headful 差别、GPU/字体和权限都影响验收。6–10 周只代表平台适配团队到位后的粗窗口，不能当成自动获得三端相同能力。

### B31 报告、CI、保留和导出

JSON 是完整结果源，HTML/JUnit 为派生报告。passed/failed/blocked/skipped/flaky/outcome-unknown/cancelled 不能在导出中丢失；JUnit 使用 properties 和附件保留原始状态，CLI 阻断优先级按文档 04。报告静态内容转义并限制链接，不能执行来自网页的脚本。

CI 默认无人值守，遇到真实 MFA/系统权限等返回 blocked；每个 job 使用自己的临时 Profile、测试租户、输出目录和秘密引用。退出或强杀后执行受控清理及污染检测；日志、截图、录制、邮件和网络正文均按敏感标记脱敏。磁盘配额、产物保留、引用计数和删除失败可观测。任务 T074/T075/T096/T097/T099。

### B32 崩溃、未知结果和补偿

状态日志在派发前写入 intent，派发后记录 dispatched，后置条件通过才记 verified；崩溃发生在任意缝隙均可能产生 unknown。CDP 响应超时、socket 断开、Worker 崩溃和用户取消不能证明动作没发生。去重键只能防止本服务重复派发，无法替代目标系统业务幂等。

补偿操作是单独授权、可审阅的新步骤，例如删除专用测试账号；失败记录 compensation-failed，不把页面返回上一页叫回滚。重启先核对目标状态，必要时隔离 Profile；至少覆盖“提交到达服务端但客户端未收到响应”的夹具。任务 T035/T095/T098/T100。

### B33 环境矩阵与配置一致性

输入为授权范围内的 Profile 配置及带时间/版本的检测证据。只读扫描记录 requested/effective/unknown、规则 ID、冲突和组合相似度；静态配置扫描与外网验证分别计时。相似配置不代表账号关联或违规；不能自动改代理/身份或给运行态 Profile 随机重生成。应用变更需生成差异草稿，使用 revision 和状态门，批量逐项返回。检测失败显示 unknown/blocked，不补造正常值。来源为现有 CDP/运行时/代理检测模块，自研配置规则；T113、AT01 验收。

### B34 Space 总览与预览

状态来自服务端 owner/lease/run，图像需 screen.read 和 Tab 范围校验，默认不持久化；高敏感页面关闭预览。最多 6 活动流、1 fps/320px 初始预算，离屏暂停，背压降频，stale 标记时间及文档版本；控制事件优先于图像。卡片接管调用同一租约服务，覆盖同 Profile 全部自动写入路径。旧图不能生成可直接派发的有效 ref。截图遮罩无法证明全部秘密已隐藏，秘密字段仍沿用 B19/B25 脱敏策略。T114、AT02/AT03 及 B05 竞态验收。

### B35 单一契约、工具集、SDK 与 Agent 手册

公共定义来自版本化中立注册表和 draft-07 schemas；显式转换生成 OpenAPI3.0.3、MCP、CLI、校验注册表、SDK 类型和手册。未知字段、转换遗漏和生成文件漂移在 CI 失败；不生成/替代业务策略。每连接选择稳定工具预设，隐藏工具不增加或减少真实权限；不支持动态工具变更的客户端重新连接。客户端和服务核对 apiVersion/contractHash，读写错误及取消/unknown 一致。TS/Python 薄客户端无 raw CDP，无通用写动作自动重试；手册包不含凭据或任意执行授权。T115–T117、AT04/AT05/AT07 验收。

### B36 站点知识包与本地复用

输入为 manifest、静态定位候选、说明和固定流程引用；检查版本、来源许可、origin、大小、路径和依赖闭包。禁止秘密、登录存储、runtime ref、任意脚本/二进制和动态工具注册；说明文本当作不可信内容。导入先预览差异，冲突不覆盖已发布版本，本机凭据变量重新绑定。站点/语言/部署变化重新验证，失配返回包不适用，不自动执行猜测步骤。首版无市场/云同步；T118、AT08 验收。

### B37 入站 BitBrowser 管理兼容子集

与 B27 的出站驱动适配分开。独立回环端点且鉴权，暂定 6 条候选 POST 管理路由，逐条核定官方版本、字段与响应后才声明支持。原生 `/api/v1` 语义、Profile 状态保护、租约和路径门继续强制。未知字段/接口明确拒绝，不返回成功再忽略；ID 映射和 requestId 可追踪。open 不返回原生 ws，要求 CDP 直连的旧脚本 unsupported；不承诺完整 1:1 或零改动迁移。T120、AT10 验收；能力不足保留原生 API/SDK 和出站适配。

### B38 快照差分、候选定位与修复草稿

delta 基于同实例/Space/Tab/frame/文档和投影范围的快照；无效 base、文档变化或超预算返回 reset/full 和原因，保留截断信息。动作始终按当前 ref/epoch/租约重验，不因 diff 延长引用寿命。定位候选只读校验，歧义不点；修复生成绑定旧 run/siteVersion 的草稿，经审阅、验证、显式发布新版本才可运行。已发布版本、旧报告/失败事实不可回写；outcomeUnknown 写不因“修复”而重复执行，不自动改断言迎合当前结果。T116/T119、AT06/AT09 和 WT26/WT48 验收。
