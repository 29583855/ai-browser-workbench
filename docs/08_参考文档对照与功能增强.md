## 4 F60 环境矩阵与配置一致性

环境页提供列表/卡片与矩阵视图。矩阵先展示可验证的普通环境项：浏览器版本、UA/UA-CH、平台、语言、时区、视口、屏幕/DPR、代理出口、扩展摘要和最后检测时间。高级 Canvas/WebGL/字体结果属于 F06 后续范围；未检测值显示 unknown，不补造为正常。

每次检测保存 requested、effective、检测器版本、运行时、时间和证据引用。规则类型为“声明/观测冲突”“配置组合重复”“出口/语言/时区差异提示”“能力不可验证”。共享 NAT、同型号 GPU、同一时区等常见配置不能判为账号违规或关联。

初始规则不超过 12 条，用固定样本和规则测试衡量准确性。100 个静态配置扫描目标 p95 ≤2 秒，不包括启动 100 个浏览器或外网出口检测；检测外网时显示队列/超时/来源。运行中的 Profile 不被自动重生成；批量改配置先生成差异草稿，再按 revision 应用到允许状态的 Profile，逐项报告结果。受限网络下出口检测可 blocked，静态比较仍可运行。

## 5 F61 Space 总览与受控预览

卡片显示 Profile、Space、标签、实际 owner、租约 generation、运行状态、最后事件、待人工项和未知业务结果。动作按钮使用已有暂停、接管、恢复服务；UI 乐观状态不能覆盖服务端租约结果。

首版采用 CDP 截图低频采样，不承诺实时视频。默认最多 6 张活动预览、每张上限 1 fps、宽 320px；离屏/折叠暂停采样，超预算先降频并标明 stale，心跳/控制事件高于图像优先级。12 卡片作为性能验收样本。后续 screencast 必须处理 ACK、大小、取消和背压，另作能力声明。

预览是只读能力，但页面截图仍可能含秘密。默认关闭预览持久化；只有获授 screen.read 的主体可看相应 Space。已知敏感区域尽力遮罩，遮罩不是完整保密证明；声明高敏感的页面默认关闭预览。接管使所有自动写路径失效，不能只停卡片所属流程；同 Profile 共享身份限制在 UI 中显示。浏览器断线或旧文档图像带时间/版本，不能据其自动点击。

## 6 F62 统一契约、精简工具与客户端

### 6.1 契约目录与生成链

拟定 `contracts/public-api.json` 为注册表，引用 `contracts/schemas/` 中的 draft-07 Schema。每个操作包含 operationId、版本、输入/输出、错误、作用域能力、读写性质、幂等分类、deadline、限制、说明、示例、REST/MCP/CLI 映射。OpenAPI 为 3.0.3 产物，需要显式方言转换和不支持特性的失败检查，不能原样粘贴 draft-07。

生成器输出 OpenAPI、C++ 校验注册表、MCP 工具声明、CLI 帮助索引、TS 类型、Python 请求模型说明和 Agent 手册。它不生成业务权限判断或可靠动作实现。CI 做产物 diff、示例正反例、Schema 方言检查、operationId 唯一性和协议契约测试；生成文件禁止手工改。服务返回 apiVersion、contractHash、能力版本，客户端检测不匹配时给出可操作诊断。

T021/T030 先建立最小注册表；T115 完成多端生成，T097/T117 完成互操作与客户端闭环。API v1 的新增可选字段不破坏旧客户；删字段、改变 outcome 或新增必填参数需新版本/迁移说明。

### 6.2 MCP 工具集与预算

提供 basic（基础观察/动作/结果）、testing（用例与断言）、debug（授权调试）和 admin（管理）预设，在连接初始化时选择并保持稳定。具体 tools/list 由固定契约生成；客户端不支持工具列表变更时，重新连接切换预设。工具隐藏只减少上下文，不代替服务端授权；basic 必须能发现必要的能力与错误。保留严格参数，不以通用 execute 任意 JSON 代替全部 Schema。

快照默认 interactive，最多 200 个可操作节点、64 KiB UTF-8，硬上限初定 512 KiB；按权限可显式展开子树。返回 bytes、nodes、truncated、omitted、documentEpoch、snapshotId。token 数估计必须标明 tokenizer/估计方式。不能截掉结果元信息后声称页面完整。

delta 仅基于同一实例、Space、Tab、frame、文档和投影范围的 baseSnapshotId；diff 自身超预算、游标失效或文档重建时返回 reset/full 与原因。即使显示差分，动作仍检验 ref 与当前文档和租约，不能用 diff 恢复已失效 ref。

### 6.3 SDK 与 Agent 手册包

TS SDK 与 Python 薄客户端只封装鉴权、deadline、requestId、结果查询、取消、事件重连与类型；不私建浏览器驱动或自动重试 unknown 写入。依赖尽量使用标准 HTTP，完整第三方生态封装另估；4 人日只包含基础薄客户端与 3 个可运行示例。

版本化集成包包含 manifest、工具/帮助摘要、权限边界、错误恢复、登录/注册/报告示例、contractHash 和变更说明。可提供供 Agent 读取的集成指南文件，但本次没有创建或安装 Codex 技能。包不夹带 API key、用户数据、自动安装命令或任意脚本执行授权。至少两个 MCP 客户端及一个 SDK 客户端通过相同夹具；每个客户端的版本、协商协议和未支持能力分别记录。

## 7 F63 站点知识包

知识包是本地版本化资料集合，不是登录态包。建议结构：manifest.json、selectors.json、notes/、workflows/、fixtures/expected-results.json、checksums.json；后缀与品牌在工程初始化时命名，不继承参考产品名称。

manifest 包含 packId/version、schemaVersion、contractVersion、适用 origin/path、语言、站点版本、定位策略及来源许可。定位候选使用 role/name/testId/结构锚点，不能保存 runtime backendNodeId；固定流程需显式版本与 hash。导入校验引用完整性、路径、内容大小、未知字段和能力，先生成差异预览。相同 ID 不覆盖当前版本，命名冲突由用户选择分支/新版本。

禁止秘密、Cookie、邮件验证码、可执行文件、任意 JS/Node/Python 脚本和动态工具注册；notes 当作不可信内容，不提升权限。origin 变化、HMR/部署版本、UI 语言变化需要重新验证候选；验证失败只影响该包适用性。导出默认不含运行截图和请求正文。包内引用的 SecretRef 只保留声明的变量槽，导入后由用户在本机绑定。

复用验收：在夹具 v1 保存登录/注册模板，另一个干净项目导入并绑定测试环境后可执行；站点 v2 改字段产生明确失配；包含路径穿越、秘密 canary、缺失依赖或脚本的包拒绝。没有应用市场、云端拉取、自动安装和同步冲突承诺。

## 8 F64 入站兼容与 F65 修复草稿

### 8.1 两个方向必须分开

- F38/T059：本软件调用已安装 BitBrowser 的接口，管理其支持的环境和受控连接。
- F64/T120：外部管理客户端调用本软件的兼容服务；由兼容映射层调用同一 Profile/Policy 服务。

入站首版暂定 6 条候选 POST 路由：`/health`、`/browser/list`、`/browser/detail`、`/browser/update`、`/browser/open`、`/browser/close`。这是待对官方固定版本核验的候选清单，不能当作当前已兼容的 BitBrowser 契约。update 的创建/修改语义、分页字段、状态编码、空值和响应格式由实报文夹具冻结；缺省不得变成删除/覆盖。

单独可选监听端点，仅回环并始终鉴权，不占用用户现有客户端端口；路径不混入原生 `/api/v1`。端口在启动时分配/配置并由状态页显示，不保证 54345。原生服务与兼容服务的 ID 映射、版本和错误有台账，跨请求 requestId 与审计可关联。

open 只承诺管理生命周期，不发放原生 CDP ws；需要 raw ws、Selenium 或任意启动参数的脚本明确 unsupported，需要迁移到原生 SDK/受控 Worker。未来若实现完整 scoped 协议代理，需另行列方法白名单、Target/Browser 级限制及租约测试，不从本轮 6 人日推导完整 CDP 兼容。运行任务期间 close/update 仍受状态和租约保护。未支持字段/方法必须明确拒绝，不能 success 后忽略。社区脚本仅作补充样本，许可未核实不复制源码，用户数据不入夹具。

### 8.2 定位修复的安全执行顺序

定位失败 → 停止派发 → 保存失败定位与脱敏快照 → 生成 role/name/testId/区域候选 → 用只读探查校验唯一性/可见性 → 展示差异与置信依据 → 人工确认新草稿 → 重新验证 → 发布新版本 → 用独立数据执行。首版只提供确定性规则候选，现有模型可建议，但不要求模型才能修复。

禁止将“更改断言为当前结果”当修复；禁止发布版本自动回写；禁止对 outcomeUnknown 的注册/保存自动再点。只有尚未派发的动作和明确可重试的只读检查，才可在新 ref、有效租约和用户确认的策略下继续。草稿记录 sourceRunId、旧/新定位、候选证据、创建主体、siteVersion 和审批状态，历史报告保持原始失败。

## 10 诊断、发布与反馈

`awb doctor --json`（拟定命令）默认只读：检查系统/架构、v142/CRT、运行时来源/版本、数据根 ACL、端口占用、SQLite/schema、可选服务、contractHash、租约/排队和磁盘配额。桌面状态页复用相同结果。返回 code、severity、affectedCapability、evidenceRef、repairHint；不展示秘密、原生调试端点或完整个人路径。需要关闭进程、改注册表或清理数据的修复不自动执行。
