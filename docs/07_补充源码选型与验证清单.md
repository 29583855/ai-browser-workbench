版本：1.3。调研日期：2026-11-03。与[原 23 项调研](02_竞品分析与开源项目调研.md)合并使用；本表新增 21 个来源条目，涉及 22 个不同仓库，合计 45 个不同仓库候选，不代表全部成为依赖。

## 1 检索方式与证据限制

第 1–6 节记录 v1.2 已完成的检索及尚待验证的候选；本次 v1.3 参考材料核查与新增模块映射见第 7 节，没有新增联网检索或构建证据。

本轮使用 GitHub 仓库搜索、公开仓库文件、git ls-remote 和官方技术文档。GitHub 搜索词包括 `browser recorder automation`、`C++14 json schema validator`、`socks5 proxy authentication gost`；结果只用于发现项目，不以排名决定复用。录制搜索出现 wildfire 等候选，但本轮优先检查维护体系较完整的 Playwright 录制模块。没有审阅的搜索命中不进入许可结论。

普通搜索引擎的本次请求出现验证页面，没有使用其中的搜索结果；GitHub core API 触及匿名额度，部分 git HEAD 解析超时或连接重置。改用公开 raw 文件与官网文档，没有绕过验证。错误、旧路径 404 和后续找到的正确入口均保存在[补充证据快照](research/research_gapfill_2026-11-03.json)。

快照共 87 条 HTTP 抓取记录：78 次 HTTP 成功，9 次失败；成功中包括 1 个搜索验证页、2 个 JavaScript 跳转壳，这 3 条不作为实质功能证据。另有 26 次仓库 HEAD 解析记录，其中 16 次成功、10 次失败；失败包含重复尝试，不能据此计算不同仓库数。快照保存抓取时间、响应哈希和文本；部分长页面为限量抓取，不代表完整归档。原 54 条证据文件保持原样。

下表固定 SHA 是本次观察点，**不是已批准依赖版本**。有些 SHA 位于开发分支，发布时应改为通过测试的 release/tag + commit + 制品哈希。只取得分支文件的项目明确标为“未固定提交”，在 T077/T065 前不得发布使用。没有克隆、构建、安装或验证任何一个项目的运行行为。
