## 3 发现的问题及解决方案

| 问题 | 影响 | 修复和验证 |
| --- | --- | --- |
| 非法时区导致构造异常后Job异步终止 | 紧接着修改可能误判为仍被占用 | 构造异常先终止Job并等待主进程及有界子进程清理，再重抛；原Debug/Release-runtime失败保留，v2通过 |
| 永久删除半途失败后桌面仍显示旧revision | 用户无法用当前版本重试purging | 失败响应仍携带命令/环境ID并刷新列表；保留实际失败状态 |
| 审计完成记录打不开/轮换失败 | 业务已执行却可能被误报为确定失败 | 所有completed审计失败均标outcomeUnknown；真实按钮同步请求延迟夹具，接受后独占审计文件，确认服务器只提交1次，再只读核对 |
| 接受审计不可写仍可能执行业务 | 缺失入口记录 | 接受日志先刷盘，失败不路由；锁住审计文件创建环境，确认没有新增记录 |
| 深中文部署目录原子临时文件超过传统MAX_PATH | 首个0.1.2候选包自检browser_start失败，不能交付 | 原子写入/有界读取/路径逐段检查及私有目录使用扩展长度路径；新增超过MAX_PATH的两次写入/替换/读取检查；旧候选包保留失败，新-r1包重新验收 |
| 工具数量/打包说明仍为16 | 新功能被旧自检误拒绝 | 自检和协议/包测试改为检查至少21项及必需生命周期工具，文档同步 |
| SOCKS夹具关监听后旧隧道仍可转发 | 断代理测试偶发通过导航 | 跟踪并关闭全部活动套接字，拒绝断开后的新握手；新增真实注册/登录及固定测试Origin，普通HTTP缺CacheStorage时显式能力检查 |
| 桌面与SOCKS同时测试时服务器登录1次、页面仍显示anonymous | 旧的异步身份响应可能覆盖新身份，结果标签过早表示就绪 | 测试页refresh引入代数并在身份/存储刷新完成后公布结果；保留并行失败，修复后两个真实测试并行通过 |
| 窗口已注册但控件尚未创建完 | 桌面测试偶发报布局不符 | 有界等待5个编辑框及列表实际创建后继续；两配置真实控件及确认删除通过 |
