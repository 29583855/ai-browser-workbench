# AI Browser Workbench 0.1.13-poc · Windows x64 开发预览

发布日期：2026-11-25。便携包构建日期：2026-11-06。

这是本项目第一次 GitHub 发布，提供 VC++2019 / v142 / C++14 构建的 Windows x64 Release 便携包，以及完整项目源码与中文文档。

## 下载与运行

- 主程序包：`AI-Browser-Workbench-0.1.13-win64-20261106.zip`，233874807 字节（约 223.04 MiB）。
- 校验文件：同名 `.sha256` 和 `.sha256.json`。
- 附加说明：`AI-Browser-Workbench-v0.1.13-poc-Release-Notes.md`。
- GitHub 自动生成的 Source code ZIP 仅是源码，运行软件应下载上面的完整便携包。

下载到本地可写目录后完整解压，先运行 `Self-Test.cmd`，通过后运行 `Start-Workbench.cmd`。后台通过 `Start-Admin.cmd` 启动。普通运行无需安装 VS、Python、Node.js 或外部数据库；附带练习网站另需 Python 3.12。

```text
SHA-256 (AI-Browser-Workbench-0.1.13-win64-20261106.zip)
424d36c4d5cab0eea2d5f7717e56f6d7b5dd160019b0dad3fae59d03ec91d59b
```

包内包含五个产品 EXE、两个测试 EXE、VC142 Release 运行库、Chrome for Testing 156.0.8078.80、启动/停止/自检脚本、源码与文档；`data` 初始为空。不要仅复制单个 EXE。

## 当前能力

独立浏览器环境管理、网页登录与表单测试、内容发布和结果提取、录制与可视化 RPA、流程调试、97 个共享工具的 MCP/Local API/CLI 接口，以及组织后台、订单权益、席位和 Windows 多节点执行。实际功能与边界以[软件功能说明](https://github.com/29583855/ai-browser-workbench/blob/main/docs/47_软件功能说明.md)为准。
