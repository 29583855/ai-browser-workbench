# 首发四场景与 POC 验收约定

日期：2026-11-03。对应 T001、T007；这是固定场景及验收输入，尚未执行的功能不能因列入本表而标完成。

| 场景 | 输入与环境 | 目标动作 | 成功证据 | 必须拒绝或明确失败 |
| --- | --- | --- | --- | --- |
| SC01 开发中 Web 登录注册 | 随机端口 localhost 夹具；每次独立内存账号；Profile A/B | 打开、唯一定位账号/密码、填写、注册、登录、读取身份 | 后端实际创建账号、设置 HttpOnly Cookie；前端身份和存储标记与账号一致；两次注册/登录事实计数 | 重复注册不增用户；错误密码不创建登录；隐藏/禁用按钮不可点击；只读输入不得改写 |
| SC02 登录后报表及文件 | SC01 登录态；受保护 `/api/report`、`/download/report.csv` | 筛选、断言行数、下载、校验文件 | 页面 rows:1 与后端报表一致；未来文件证据需完成下载事件及内容哈希 | 未登录返回 LOGIN_REQUIRED；下载路径/超限/中断必须失败；当前下载动作尚未实现 |
| SC03 多环境与代理 | A/B 两身份及匿名 C；HTTP 夹具代理 | 启停、切换、重开、读取 Cookie/LS/IDB/Cache/SW、代理出口、断代理 | 三目录身份不串；正常关闭确认 Job 清空；重开恢复会话；实际请求经过代理；代理停止后导航失败 | 运行中重复启动拒绝；跨域拒绝；崩溃不重试提交；不得静默回退直连；其他三类代理另验 |
| SC04 AI/外部自动化调用 | 官方 MCP Python SDK；JSONL CLI；原生工作台 | 握手、列工具、创建启动停止、定位/动作/断言、撤销控制 | 相同注册表/参数校验/服务处理；真实工具结果；旧租约与旧文档/重启引用拒绝 | 未初始化、未知命令、额外字段、超长协议、无租约均拒绝；不开放任意页面脚本/原生 CDP；正式 REST/SDK/AI 规划尚未实现 |

夹具入口：`python tests/fixtures/web_app.py --port 3000`，然后打开 `http://127.0.0.1:3000/login`。自动化脚本使用随机端口，以免碰到开发中应用。测试用户名为 alice-test/bob-test，口令为运行中 canary 测试数据，不是生产账号或后台登录凭据。

每次测试必须创建全新证据目录和 Profile 根目录；结束实际停止自有浏览器和服务器。业务成功用服务端事实加页面断言，不以点击命令成功作为注册/登录成功。只读等待可重试；提交不重试。进程崩溃测试只操作该测试启动并保存句柄的进程，不按程序名终止系统浏览器。

当前自动化覆盖 SC01、SC03 与 SC02/SC04 的 POC 子集。`tests/integration_browser.py` 验证登录注册、反向业务、隔离、报表文本、引用/租约拒绝和双层崩溃；`tests/integration_proxy.py` 验证 HTTP 出口/断代理；`tests/integration_mcp.py` 使用官方 SDK 验证协议互操作。截图为单帧证据；表单录像另通过测试专用CDP screencast采集真实帧和时间戳并编码GIF，保留帧清单。SC02 下载与 SC04 正式 REST、模型规划没有完成。

四场景目录冻结即 T001；首批可复现夹具、数据与断言落实即 T007。T009表单录像和T010的OOPIF/Shadow能力限制实验已完成；T013还要求可见窗口焦点等矩阵，保持进行中。
