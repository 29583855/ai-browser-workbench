# VE011 编辑历史、剪贴板与恢复验收

日期：2026-11-04。适用版本0.1.9-poc，Windows11 x64本机范围。专项子项完成不等于T042/T043/T095父包全部完成。

验收对象为已应用到FlowDocument的节点、属性、布局和当前子流程；不包含未应用的编辑框文字、运行时变量、浏览器登录态或SecretRef凭据库。

| 要求 | 实现与验证 |
| --- | --- |
| 撤销/重做 | 完整模型、布局、flow快照；新编辑清重做；两条链共100项/8MiB；核心测试含大模型字节限制、子流程及属性历史 |
| 复制/粘贴/剪切 | 专用Windows剪贴板，256KiB、有限节点结构和坐标；内部ID重映射、外部连线留空；核心测试跨文档、坏数据不部分粘贴，真实窗口测试剪切及撤销 |
| 自动保存 | 5秒Win32计时器，每窗口独立恢复文件、同目录原子替换；单份1MiB、最多50份，超限明确报错且不删旧文件 |
| 崩溃恢复 | 测试强制终止工作台，重启后从原生文件选择器恢复，节点/布局完全一致；恢复必须另存，不执行流程 |
| 并发revision | 同路径独占锁+revision比较；旧编辑器不能覆盖新草稿，坏文件不能替换当前文档；核心测试保留原文件字节 |
| 清理及退出 | 确认关闭只删本窗口恢复文件；主窗口退出保留打开草稿，模态文件框期间阻止退出；真实桌面检查 |

最新双配置三轮证据见[最终回归](../execution/evidence/2026-11-04-visual-rpa/final-regression-r2/report.json)，每轮recovery有6组，canvas有19项，报告绑定二进制SHA256。早期恢复失败及修复见[测试文档](../32_可视化RPA实施与测试记录.md#4-已发现问题解决办法及复验)。

边界：崩溃恢复最多丢最近5秒已应用修改；剪贴板不复制依赖子流程/输入Schema，须显式修正并重新校验；手动输入到节点的静态值会随节点保存/复制，录制器生成的槽不带原始输入值。实体多屏、系统IME和屏幕阅读等仍归VE027。

0.1.10复盘补充：修复恢复写入失败发生在WM_DESTROY导致无法阻止退出的问题；主工作台现先预存全部画布，失败保留全部窗口。文件删除后重新保存。新增单/多画布立即退出、单/多画布满额、独占文件及删除文件共6场景，Debug/Release通过。细节及失败证据见[文档34](../34_项目功能复盘与回归测试报告.md)，不扩大本项至未应用属性或系统会话关机保存。
