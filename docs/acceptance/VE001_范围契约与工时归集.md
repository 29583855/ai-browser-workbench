# VE001 范围、契约与工时归集验收

日期：2026-11-04。范围：设计与归集任务。它的完成不代表录制/画布/适配已经全部实现。

## 1 版本及边界冻结

第一期执行DSL固定1.0，不增加输入关键字、不修改现有步骤上限。第二期变量/数组/foreach及新断言拟使用1.1；该版本仅是设计保留号，在Schema、迁移器、执行器和三端映射实现前不得发布或运行。旧0.1设计示例不能静默改名为1.0。

草稿容器版本1.0：draftVersion、revision、definition、views。definition完整保留源字段，未知版本/节点只读；允许保存非法图，但导出和发布必须经ValidateWorkflow且valid=true。views以$main/子流程名及节点ID映射{x,y}；视图不进入执行hash。坐标范围±100000逻辑像素，撤销至多100项或8MiB。外部JSON解析深度48、文件1MiB，执行定义仍256KiB。

## 2 录制契约冻结（当前预览）

三个工具为recorder_start、recorder_read、recorder_control，均需profileId及当前lease；control操作pause/resume/stop。会话使用recordingId并绑定唯一pageId/CDP会话；document为隔离世界生成的新文档UUID，各文档源事件序号必须连续。外层返回state、complete（仅表示采集无已知缺口）、scope、events、draft、requiredConfiguration、pageActionsDispatched、fieldValuesCaptured。完整可视化会话模型的时间/frame字段扩展归VE003，当前不声称该包完成。

事件只保留sequence、document、kind、selector、sensitive、pageId、origin。kind为document/fill/select/click/unsupported/gap；selector只用于当前主文档唯一CSS，普通录制使用结构路径；稳定候选在元素拾取中提供。任何输入值、按键、composition文本、标签正文、Cookie/令牌、完整URL及截图都不进入事件队列。普通填写和密码都生成必填参数槽；敏感输入另外提示credential-binding，目前仍需用户手动绑定输入，不能宣传已实现SecretRef库。

上限为1000事件/8MiB，源端在达到预算后停止输出并报告缺口；主机不丢旧记录来伪造连续性。重复注册拒绝；暂停先结算当前输入，恢复不补录；停止删除预注册新文档脚本及监听。跨文档目前明确提示审阅；iframe/复杂控件标为不完整。跨frame/OOPIF、Shadow、富文本、文件及多选控件不能用本预览验收关闭。
