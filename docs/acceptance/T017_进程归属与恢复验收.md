# T017 进程归属与启动恢复验收

日期：2026-11-04。结论：本地进程生命周期工作包通过；不包含节点Agent/跨机器接管。

浏览器以挂起状态创建，加入本Service独占且关闭即清理的Job；恢复运行前将PID、创建FILETIME、镜像、实例ID、服务PID及归属类型写入环境awb-process-owner.json并刷盘。正常停止只作用于自有Job，不以可复用PID判断归属。启动失败显式终止Job并有界等待其退出，再返回失败。

重启时InspectRecovery同时检查进程创建时间和镜像。browser_status.recovery区分no-record、recorded-process-exited、stale-process-identity、live-process-unowned、process-unverifiable、invalid-record；当前对象拥有的活动实例报告owned-by-current-service。未知归属/不可验证/损坏记录阻断启动、修改、删除及无当前对象的停止，不自动杀或接管外部进程。已退出/身份不匹配的陈旧记录不会误杀新的同PID对象。

验证：[Debug恢复](../execution/evidence/2026-11-04-implementation/Debug-recovery/report.json)、[Release恢复](../execution/evidence/2026-11-04-implementation/Release-recovery/report.json)，每配置4组：本服务真崩溃/Job清理/重启；外部活进程记录阻断不杀；创建时间不符不误杀；损坏记录拒绝。非法时区构造失败后的清理见runtime报告。原浏览器崩溃/停止集成仍通过。

恢复只观察记录并报告人工处理依据，不从磁盘记录重建Job控制权。跨服务接管、透明CDP重连和流程续跑仍属于其他任务，不能由本项验收推导完成。
