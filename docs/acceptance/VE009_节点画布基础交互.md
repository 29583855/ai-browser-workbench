# VE009 节点画布基础交互验收

日期：2026-11-04。范围：节点库、拖入、移动、缩放、平移、框选、命中及基础键盘。图模型使用稳定节点ID，布局独立于执行定义；本项不包含完整属性向导、自动保存、调试或AI适配。

交付源码：`src/ui/flow/flow_editor.cpp`、`include/awb/flow_document.hpp`、`src/core/flow_document.cpp`，同时登记CMake及原生VS2019工程。`workbench.exe`顶部“可视化流程编辑器”进入，可从节点库拖入或按Enter插入；Ctrl+点击增选，空白处框选，左键移动选区，中键平移，滚轮围绕鼠标缩放，箭头移动，Delete删除，Ctrl+Z/Y撤销/重做，Ctrl+D复制选区。编辑属性使用原生JSON框，不宣称完整表单向导已完成。

模型回归验证布局不改变完整执行定义、15种DPI/缩放逆变换、复制内部ID、撤销/重做及100项预算；窗口回归验证真实手势、节点库拖入和200节点性能。Debug/Release三轮逐项报告及错误修复在[统一测试文档](../32_可视化RPA实施与测试记录.md)。

验收仅覆盖本机的基础交互，不把DPI渲染目标代替实体多显示器测试。旧DSL的图预算/不可达/环/递归仍通过统一校验阻止发布；非法草稿可保存，不能直接导出或执行。完整连线向导和错误定位、自动保存/恢复、版本迁移分别保留在VE010/VE011/VE012。
