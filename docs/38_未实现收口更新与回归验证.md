## 5. 操作与复测

完整样例：[workflow-files-v1.1.json](examples/workflow-files-v1.1.json)。启动`python tests/fixtures/web_app.py --port 3000`，创建允许该来源的环境，启动浏览器、取得租约、发布样例。准备名为`fixture.txt`的普通文件，运行输入：

```json
{"uploadPath":"E:/test/fixture.txt","downloadDirectory":"E:/test/downloads"}
```

父目录须已存在。运行成功后应有下载fixture.csv、页面计数2和echo为B。readTexts目标变量必须是有界字符串数组；元素maxLength至少4096，数组maxItems覆盖节点预算（0..32）。数组初值使用带Schema的literal，完整字段见样例；网页输出按敏感值传播，不落盘原始值。

下载配置作用于当前Profile浏览器。每次新下载流程先配置，再触发动作，再等待；配置清空已结束跟踪记录，活动下载期间禁止重置。downloadWait按本次配置后的唯一建议文件名匹配；重复名称、事件超限、取消、完成路径不可用及文件异常明确失败。超时不取消、不删除文件、不重试点击，应核对实际下载状态。当前等待上限10000ms；取消/断网/重名/跨版本完整矩阵仍待验收。

桌面菜单“环境库与本地后台”：列表/政策/概览直接查看；选中环境后用名称框创建分组、保存模板和导出配置。导出结果可直接保存为JSON，再从选择器框填写完整文件路径并执行“从JSON导入配置”。更新、删除、实例化和批操作文件仅含工具arguments：

```json
{"id":"模板ID","expectedRevision":1,"name":"新环境"}
```

```json
{"operations":[{"command":"browser_start","arguments":{"profileId":"环境ID","headless":true}}],"onError":"stop"}
```

分组最多100成员、本地库最多1000资源，每批导入/导出/操作最多32项。删除分组/模板不删除环境。模板revision用于并发控制及实例化；history读取历史，rollback按sourceRevision复制为新版本。

SQLite升级到v6，旧v1-v5升级前保留`.before-v6.<随机ID>.sqlite3`快照，旧迁移字节/哈希不变。升级后不可再用旧程序写同一数据根。配置导出不包含会话和凭据，不能替代完整备份或跨Windows用户迁移。
