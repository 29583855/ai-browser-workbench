# AI 浏览器自动化工作台功能说明

更新日期：2026-11-05。适用版本：0.1.13-poc，Windows x64 开发测试版。本文依据当前源码、97 个共享工具的契约及现有验收记录整理。软件尚未达到完整商业发行验收标准。

配套阅读：[软件使用与运行环境配置](48_软件使用与运行环境配置指南.md)、[源码编译环境搭建](49_源码编译环境搭建指南.md)。本文说明当前能力；历史规划中的目标不自动视为已经实现。

## 1 软件用途与组成

工作台管理独立浏览器环境，让人工、脚本和 AI 在明确的网站范围内执行浏览器操作。典型用途包括 Web 系统注册登录测试、填写表单、业务按钮验证、内容发布、搜索采集，以及对指定内容执行点赞、评论和回复。步骤可编排成流程，交给本机或指定 Windows 节点执行。

后台提供客户组织、套餐、订单、支付、续费、席位、设备、运行槽、用量和节点调度。用户可以先使用免费自动化能力，再根据组织环境数、并发或额外资源需求购买扩展。

| 程序 | 作用 | 使用者与入口 |
| --- | --- | --- |
| `workbench.exe` | 原生 Win32 桌面，管理环境、操作网页、录制、编排和调试流程 | 人工操作者；`Start-Workbench.cmd` |
| `workbench-cli.exe` | JSONL 命令服务，或本机鉴权 HTTP API | 脚本及第三方软件；`Start-CLI.cmd` / `Start-API.cmd` |
| `workbench-mcp.exe` | MCP stdio 工具服务 | 支持 MCP 的 AI 客户端 |
| `workbench-admin.exe` | 独立 C++ 后台，内嵌中文 Web 管理门户 | 客户、组织管理员、财务和平台运营人员；`Start-Admin.cmd` |
| `workbench-node.exe` | 主动向后台连接的独立 Windows 执行节点 | 多机部署；`Start-Node.ps1` |

另有 `awb-core-tests.exe`、`awb-storage-tests.exe` 两个测试程序。原生 VS2019 解决方案共 9 个项目，包括上述 7 个 EXE 和 2 个静态库。

**实际打开的是 Chrome for Testing 156.0.8078.80。** 工作台通过 CDP 管理独立的 Chrome 进程和用户目录；桌面窗口不是内嵌网页浏览器。当前没有自研 Chromium 指纹内核，也不能据此承诺任意网站的反关联或风控兼容效果。

## 2 浏览器环境管理

| 功能 | 当前行为 | 使用条件与边界 |
| --- | --- | --- |
| 独立环境 | 不同 Profile 使用独立目录、Cookie 和站点存储 | 网站仍可按自身规则过期登录态 |
| 生命周期 | 新建、修改、归档、回收、恢复、永久删除 | 修改及删除检查运行状态、引用和当前 revision |
| 冲突控制 | 使用 revision/CAS 防止旧界面覆盖新配置 | 冲突后重新读取并确认变更 |
| 环境分组 | 创建、重命名、调整和删除分组 | 不改变浏览器身份隔离方式 |
| 模板 | 创建、更新、实例化、查看不可变历史及回滚 | 模板是配置复用入口 |
| 配置导入导出 | 导出配置、校验后导入 | 不等于跨机器搬迁登录态或解密 DPAPI 凭据 |
| 持久批处理 | 查看批次、分页、归档及保留管理 | 查看每项结果，不把部分完成当作全部成功 |
| 代理和区域 | 无认证 HTTP/SOCKS5 代理，UA、语言、时区 | 实验范围；区域覆盖以启动报告的实际目标范围为准 |

运行中或仍被资源引用的环境不能直接破坏性修改或删除。永久删除需要确认完整环境 ID；文件占用导致 `purging` 时应排除占用后重试，不能用删除数据库记录掩盖残留。

免费政策允许使用代理；当前实现尚未覆盖 HTTPS 代理、代理认证、SSH 隧道及完整网络泄漏测试矩阵。配置 UA/语言/时区属于浏览器运行参数与主目标覆盖，不是指纹内核改造。

## 3 网页操作、探查与功能测试

### 3.1 基础操作

- 启动、查询和停止受管浏览器，导航到环境允许的来源。
- 获取当前主文档的可访问性语义快照，按唯一 CSS 定位元素。
- 填写输入框、文本域及基础 ContentEditable，点击按钮，按精确 value 选择原生单选或多选框。
- 读取文本，按精确文本等待结果，执行文本、URL、数量和状态断言。
- 单文件上传，设置下载目录，等待并核对下载完成，获取 PNG 截图。
- 按 Schema 提取结构化数据或字符串数组，执行有界动作批次。

自动化操作需要环境实例及排他控制租约。租约包含 `owner/token/generation`，元素引用 `ref` 只在其所属实例和文档范围有效；导航、切页等操作后应重新定位。唯一定位匹配多项会拒绝执行，不会自行点击第一项。

点击返回成功表示输入已派发。登录成功、文章发布成功、订单付款成功等，应继续读取独立结果或核对服务器状态。动作批次不是网页业务事务，不能回滚已经提交的网站操作。

### 3.2 方便人工确认的工具

| 功能 | 适合解决的问题 |
| --- | --- |
| 元素探查与高亮 | 确认 CSS 选中的按钮、字段是否正确 |
| 只读动作预览 | 检查可见、禁用、遮挡等当前条件，再决定是否执行 |
| 鼠标拾取 | 点击网页元素后读取定位信息；拾取期间点击被截获，退出不补发 |
| 功能候选发现 | 根据名称、标签、语义寻找“登录”“发布”等候选元素 |
| 页面管理 | 列出、打开、切换和关闭受管页，避免操作错误标签页 |
| 页面事件与重连 | 轮询页面元数据，识别事件缺口，显式恢复 CDP 连接 |
| 运行诊断 | 收集 Console、异常及网络元数据，与流程步骤关联 |

功能发现使用主文档标签与语义启发式。候选结果需人工或规则核对，不能保证任意网站都唯一识别正确。诊断不等于完整录制网络正文、所有跨帧行为或完整端到端监控平台。

### 3.3 注册登录及内容业务

软件可以执行“打开网站 → 输入帐号密码 → 登录 → 断言身份 → 打开发布入口 → 填写文章 → 发布 → 核对结果 → 搜索 → 提取列表 → 操作指定目标”的流程。文章正文、目标文章 ID、评论父 ID 等应由输入或明确筛选规则确定。

仓库自带两类练习站：`tests/fixtures/web_app.py` 用于注册登录、状态和隔离检查；`examples/content-lab` 用于文章发布、搜索分页、点赞、评论和回复。它们需要额外的 Python，仅用于练习和开发测试，不是产品运行依赖。

## 4 可视化录制、流程编排与调试

| 功能 | 已实现内容 | 需要注意 |
| --- | --- | --- |
| 网页录制 | 当前主文档录制，暂停、恢复、停止及草稿生成 | 所有输入值转换为参数槽，不保存原文；检查缺项 |
| 原生画布 | 拖拽节点、连线、JSON 属性编辑、撤销/重做，布局与流程分离 | 属性需点击应用才进入已保存草稿 |
| 流程结构 | DSL 1.0/1.1，类型变量、分支、循环、foreach、子流程 | 以校验器与当前契约支持范围为准 |
| 发布与执行 | 校验、不可变版本及 SHA-256、异步运行、状态与运行列表 | 固定版本运行；编辑草稿不改变已发布版本 |
| 运行控制 | 暂停、恢复、取消 | 暂停在步骤边界生效；取消不能撤回已经提交的业务 |
| 调试器 | 断点、首节点暂停、单步、stepOver、stepOut、脱敏变量观察 | 调试时同样受租约、来源与秘密保护限制 |
| 草稿恢复 | 保存已应用属性、恢复编辑状态 | 不是浏览器业务任务的崩溃自动续跑 |
| 定位修复 | 生成可审阅的修复草稿 | 保留原失败记录和原发布版本，审阅后重新发布 |

推荐先用测试帐号录制一条最短业务路径，再补齐起始 URL、允许来源、输入 Schema、每次写操作的后置断言，最后校验发布。涉及登录等秘密时，使用 SecretRef 或私有运行输入，不将真实密码写进共享流程文件。

## 5 凭据、AI 与站点知识包

凭据由 Windows 当前用户 DPAPI 保护，支持作用域、SecretRef、轮换、删除及审计。另一台机器或另一个 Windows 用户不能直接使用复制来的密文。使用秘密后，实例截图可能被保护策略阻断；这是正常保护行为。

AI 可通过 MCP、HTTP API 或 SDK 调用实际网页工具。软件另提供兼容 `chat/completions` 的模型配置、预算与受校验流程草稿生成。模型服务地址及密钥由部署者配置；草稿应审阅后再发布执行，生成成功不代表网站业务已完成。

站点知识包支持预览差异、版本导入、列表和导出，采用数据包形式，不自动执行包内脚本。不要将其理解为已覆盖所有网站的适配插件市场。

## 6 外部软件和 AI 接口

桌面、JSONL CLI、MCP stdio 和本机 HTTP API 共用业务实现与 97 个工具注册项。Python/TypeScript 薄 SDK提供契约与调用封装。准确参数见 [工具契约](contracts/tools-v1.json)，运行时可通过工具列表核对版本。

| 方式 | 使用场景 | 关键约束 |
| --- | --- | --- |
| JSONL CLI | 本机脚本持续调用 | 一行一条 UTF-8 JSON 请求，读取对应 ID 的响应 |
| MCP stdio | AI 客户端工具调用 | 由客户端启动服务并完成 MCP 初始化 |
| Local HTTP API | 同机其他进程调用 | 仅回环、启动时轮换 Bearer 令牌，拒绝网页跨域调用 |
| Python / TypeScript SDK | 编写自己的自动化软件 | 跟随当前生成契约；不绕过业务校验 |

各启动脚本默认使用不同数据根。桌面创建的环境不会自动出现在 CLI 的独立根中；同一个根不能由多个进程同时使用。需要共享控制时，复用单一服务进程，不绕过根锁。

## 7 管理后台、免费档与商业功能

### 7.1 账号与权限

支持本地注册、登录、客户组织、组织成员，以及 `owner/admin/finance/member` 权限。平台运营权限独立于客户组织角色。首次平台管理员用初始化密钥建立，没有通用默认密码。席位邀请令牌由操作者自行交给被邀请人，当前不自动发送邀请邮件。

### 7.2 套餐和账务

已提供套餐价格快照、订单、线下真实流水核实、购买续费、预付秒数、席位邀请与回收、设备管理、全局运行槽、用量、账本、全额退款、发票/红票登记及审计。

发票登记不等于自动对接税务开票。订阅续费需要明确创建订单并付款；不提供自动代扣委托。不同组织的数据及管理权限隔离，客户端连接后台后按中央权益进行准入和用量管理。

### 7.3 当前免费规则

| 项目 | 默认规则 |
| --- | --- |
| 环境容量 | 每组织 10 个，跨项目、设备与节点合计 |
| 同时运行槽 | 默认 10 个，和环境容量分别核算 |
| 命名席位 | 默认 1 个 |
| RPA / Local API / AI 调用 / Web 测试 | 核心功能免费，不要求购买 |
| 用户自有执行节点 | 不因使用节点本身强制购买 |
| 代理 | 免费政策允许；实际协议支持范围见第 2 节 |
| 收费扩展 | 超过组织环境/并发容量，或明确购买额外资源与服务 |

该规则已替代早期“2 个内免费且不能代理”的设想。10 并发是本项目默认规则，不代表比特浏览器的实际并发政策。纯离线引擎的权益试算与 `doctor` 结果不等于中央全局配额强制执行，也不是防篡改商业许可证。

## 8 官方支付与企业身份登录

| 集成 | 当前已实现 | 验收边界 |
| --- | --- | --- |
| 支付宝 | RSA2 签名、预创建、查单、通知验签、全额退款及查询 | 已做本地协议正负向验证；真实商户待验收 |
| 微信支付 V3 | Native 下单、商户签名、平台验签、AES-GCM 通知解密、查单、全额退款及查询 | 同上；需要真实平台密钥和商户配置 |
| Stripe | Checkout、查单、Webhook 原文验签及密钥轮换、全额退款及查询 | 同上；区分测试/正式模式 |
| OIDC | Discovery、授权码、S256 PKCE、RS256/JWK、claims/state/nonce 与浏览器绑定 | 本地协议及真实浏览器登录已测；企业 IdP 兼容待验收 |
| 桌面 SSO | 门户生成 120 秒单次连接码，桌面或 `account_connect_code` 交换 | 到期或重复使用拒绝 |

支付仅支持 CNY、全额退款和明确下单续费。通知和查询经过验证后才能产生账本/权益，同一事实幂等入账；付款页面跳转不能授予权益。网络结果未知时先查询，不重复发起扣款或退款。

OIDC 使用 `issuer/sub` 显式绑定。相同邮箱不自动合并已有本地账号。退出先撤销本地会话，再进入受信 IdP 退出入口；IdP 可能要求确认，当前不保存 `id_token_hint`。MFA 和目录同步应在实际身份系统中配置与验收。

支付、OIDC 的真实参数未提供时默认关闭并留空，相关动作明确报未配置。配置方法见[运行配置手册](48_软件使用与运行环境配置指南.md)。

## 9 多机任务调度

当前采用单个持久协调器和多个 Windows 出站节点。节点用 5 分钟注册码登记，生成独立 RSA 身份并由当前用户 DPAPI 保护，经门户批准后领取任务。

中央管理项目、网站来源、成员、环境归属节点及账号、配置摘要和 generation。流程发布为不可变版本，任务经 FIFO 持久队列、Outbox/Inbox/ACK 交付；中央统一核算环境容量与运行槽。

中央租约为 20 秒；节点按 18 秒本地单调期限保护，并在每次实际 CDP 发送前检查资格。取消、失联和重启会停止或阻断继续操作；旧任务可能进入 `unknown`，不自动重放。只有确认真实浏览器及受管 Job 停止后才释放槽，网页业务结果仍需单独核对。

支持节点维护、撤销、取消与未知结果核对，支持选择 Windows 当前用户 MY 证书库的客户端证书，附 HTTPS/mTLS 分离入口模板。实际证书握手和第二台物理 Windows 仍未验收。

当前不包含多协调器 HA、PostgreSQL、多地域调度、Windows 服务跨用户桌面代理或跨节点迁移浏览器用户数据。
